# FASTSEEK.X

> FAT（ファイル管理領域）アクセスの常駐キャッシュドライバ。ファイルのクラスタチェーン
> 情報をメインメモリに憶えておき、ディスクの読み書き性能を上げます。

---

## リファレンス（一次資料要約）

### 起動・コマンドラインオプション

書式:

```
FASTSEEK ［管理領域サイズ］［パラメータ］
```

コマンドラインからも`CONFIG.SYS`の`DEVICE=`からも常駐できます。

新規常駐時のみ有効なパラメータ:

| パラメータ | 効果 |
|-----------|------|
| `-b 数値` | 管理領域のサイズをKB単位で指定する |

新規常駐時・常駐後の再指定どちらでも有効なパラメータ:

| パラメータ | 効果 |
|-----------|------|
| `-x` | IOCS経由のディスクアクセスをエラー扱いにする |
| `-l` | 現在のバッファ内容をロックする |

上記のうち登録時のデフォルトに関するもの:

| パラメータ | 効果 |
|-----------|------|
| `-u` | ロックを解除する |
| `-y` | IOCS経由のディスクアクセスでバッファをクリアする |

常駐中のインスタンスに対してのみ意味を持つパラメータ:

| パラメータ | 効果 |
|-----------|------|
| `-c` | バッファの内容をクリアする |
| `-i` | キャッシュの状態を表示する |
| `-v` | より詳細な状態を表示する |
| `-r` | 常駐を解除する |

キーボードから`CTRL+E`を押すとバッファがクリアされる（この動作はFASTIO/FASTOPEN/
FASTSEEKの3ドライバ共通）。

### 使用上の注意

- 複数の高速化ドライバ（FASTIO/FASTSEEK/FASTOPEN）を併用している場合、解除時は
  常駐させた順と逆順に解除する必要がある
- X68030シリーズ以外の機種では、これらのドライバを常駐させた後に`FDDEVICE`を
  常駐させることができなくなる

run_command("FASTSEEK -b 256")
