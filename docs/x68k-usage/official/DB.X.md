# DB.X

> MPU68000用シンボリックデバッガ（XDebugger）。ソースプログラムのイメージでブレークポイント・メモリ・レジスタ操作、トレース実行などを行います。X68000本体には付属せず、XC（C compiler PRO-68K）開発キットに同梱されます。

---

## リファレンス（一次資料要約）

### 起動

```
DB [<スイッチ>] [<ファイル名>] [<コマンドライン>] ↵
```

| 項目 | 説明 |
|------|------|
| `<ファイル名>` | デバッグ対象の実行可能ファイル（省略可、起動後に`R`コマンドで読み込むことも可） |
| `<コマンドライン>` | デバッグ対象プログラムに渡す引数（省略可、起動後に`C`コマンドで設定することも可） |

#### スイッチ一覧

| スイッチ | 引数 | デフォルト | 説明 |
|---------|------|-----------|------|
| `/r` | なし | 非使用 | デバッガの入出力をCON→AUXに切り替えて起動（RS-232C経由で別端末から操作） |
| `/c<メモリサイズ>` | KB単位の数値 | `128` | `!`コマンドでOSコマンドを実行する際に確保する空きメモリサイズ |

---

### コマンドの書式（共通ルール）

```
<コマンド名><パラメータ> ↵
```

- `<コマンド名>`は1〜2文字のアルファベット。`<パラメータ>`は値・アドレス・シンボル・式など。
- 複数コマンドを`:`で連結して1行にまとめられる（例: `D:L:Y/N:¥` — ダンプ→逆アセンブル→ポーズを繰り返す）。
  ✅ `D 3000 300F:Y/N`でix68k検証済み（`D`実行後`Y/N ?`のポーズプロンプトが表示された）。
- `¥`コマンドで直前のコマンドラインを`CTRL+C`まで繰り返し実行できます。
  ❌ ix68k検証で単体実行（`¥`+RETURN）すると`Command error.`となり動作せず（原因不明、
  半角`\`でも同様に失敗。複数回試行済み。`:`区切りの一部としてではなく単独コマンドとして
  打った場合の挙動が不明、要再調査）。

#### 数値・演算子の指定方法

| 種別 | 指定方法 | 例 |
|------|---------|-----|
| 16進 | 数値をそのまま入力 | `1F` |
| 10進 | 先頭に`¥` | `¥100` |
| 2進 | 先頭に`_` | `_1010` |
| シンボル／システム変数／レジスタ | 先頭に`.` | `.PC` `.Z3` |

演算子: `+` `-` `*` `/` `&`(論理積) `\|`(論理和) `!`(論理否定) `^`(排他的論理和) `%`(剰余)。式中にスペース・タブを入れてはなりません。

#### サイズ指定

| 記号 | 意味 |
|-----|------|
| `S` | バイト |
| `W` | ワード（省略時のデフォルト） |
| `L` | ロングワード |

#### 共通パラメータ

| パラメータ | 範囲・書式 |
|-----------|-----------|
| `bp`（ブレークポイント番号） | `0`〜`9`（最大10個） |
| `cp`（メモリチェックポイント番号） | `0`〜`9`（最大10個） |
| `cd`（チェック条件） | `0`＝Not Equal（`<>`）／`1`＝Equal（`=`） |
| `drive`（ドライブ番号、R@/W@用） | `0`＝カレント／`1`＝A／`2`＝B（仮想ドライブ・仮想ディレクトリの実ドライブは不可） |
| `reg`（レジスタ名、X用） | `d0`〜`d7` `a0`〜`a7` `ssp` `usp` `sr` `ccr` `pc` |

### コマンド一覧

#### ブレークポイント操作

| コマンド書式 | 機能 | 備考 | 検証 |
|---|---|---|---|
| `B` | ブレークポイントの表示 | 未設定時は`no break pointer` | ✅ |
| `B [<bp>] <address> [<count>]` | ブレークポイントの設定 | アドレスは偶数のみ。`<count>`省略時は1（通過1回で停止） | ✅ |
| `BC <bp> [<bp>...]` | ブレークポイントの削除 | `*`で全削除 | ✅ |
| `BD <bp> [<bp>...]` | ブレークポイントの一時無効化 | `*`で全無効化。`BE`で再有効化可 | ✅ |
| `BE <bp> [<bp>...]` | ブレークポイントの有効化 | `*`で全有効化 | ✅ |
| `BR` | 全ブレークポイントの通過回数クリア | | ✅ |

#### メモリ操作

**重要（ix68k検証で判明）**: `<size>`はコマンド名に**スペースを空けず直接連結**する
（例: `MES 3000 12`。`ME S 3000 12`のように空白を入れると`Bad parameter.`になる）。
マニュアルの`ME [<size>] ...`という角括弧表記だけでは分からない実装仕様。

| コマンド書式 | 機能 | 備考 | 検証 |
|---|---|---|---|
| `D [<size>] [<range>]` | メモリ内容のダンプ（16進＋ASCII） | `<range>`省略時は前回表示の続きから128バイト | ✅ |
| `F [<size>] <range> <data>` | 指定範囲を`<data>`で埋める | サイズ省略時はW（ワード）単位で埋まる（`F 3000 300F AA`→`00AA`の繰り返し） | ✅ |
| `ME[<size>] [<address>] [<data>]` | メモリ内容の編集 | `<data>`省略で対話編集モード。`'ABCD'`のような文字列指定も可（この場合バイト単位固定） | ✅（`MES <addr> <data>`） |
| `MEN [<size>] [<address>]` | メモリ内容の編集（現在値を表示しない） | | 未検証 |
| `MEP [<address>] [<data>]` / `MENP [<address>]` | I/Oポート用編集（バイトアクセスでアドレス+2ずつ進む） | | 未検証 |
| `MM <range> <address>` | メモリブロックの移動 | 移動元と移動先が重なっていても正しく転送される | ✅ |
| `MS[<size>] <range> <data>` | メモリ内容の検索 | 文字列指定時（`'ABC'`）はサイズ自動的にS。ヒット位置（先頭アドレス）を返す | ✅（`MSS <range> <data>`） |

#### メモリチェックポイント操作

**重要（ix68k検証で判明）**: `N`も`<size>`と`<cp>`をコマンド名に直接連結し
（`NS0`のように）、その後の`<address> <cd> <data>`はスペース区切り
（例: `NS0 3005 1 12`）。`cd`と`data`の間に`=`を書く（`1=12`）とエラーになります。

| コマンド書式 | 機能 | 備考 | 検証 |
|---|---|---|---|
| `N` | メモリチェックポイントの表示 | 未設定時は`no memory check pointer` | ✅ |
| `N[<size>][<cp>] <address> [<cd>] [<data>]` | メモリチェックポイントの設定 | トレース実行中に条件成立で停止。`<data>`省略時は現在値を採用 | ✅（`NS0 <addr> <cd> <data>`） |
| `NC <cp> [<cp>...]` | メモリチェックポイントの削除 | `*`で全削除 | ✅ |
| `ND <cp> [<cp>...]` | メモリチェックポイントの一時無効化 | `*`で全無効化 | ✅ |
| `NE <cp> [<cp>...]` | メモリチェックポイントの有効化 | `*`で全有効化 | ✅ |

#### アセンブル・逆アセンブル

| コマンド書式 | 機能 | 備考 | 検証 |

## ix68kでの利用

### 入手先

- retropc.net配布（Sharp/Hudson、著作権表示の通り再配布条件あり）:
  http://retropc.net/x68000/software/sharp/xc21/ から`XC2101.LZH`（538.0KB、
  XCシステムディスク1 (2000/04/15)）をダウンロード。`/BIN/DB.X`として収録されています。
  ページはShift_JIS・httpのみ（httpsは証明書の検証に失敗するため、
  `http://`のURLで取得する）。
- **`arc/XC2101.LZH`にローカル保存済み**（2026-08-14取得）。再検証時は再ダウンロードせず
  これを使うこと。

### インストール（SYSTEM_HD.HDSへの導入手順）

```sh
# 1. ダウンロード（arc/XC2101.LZHにローカル保存済みならそれを使う）
curl -L -O "http://retropc.net/x68000/software/sharp/xc21/XC2101.LZH"

# 2. 展開（unar、要 brew install unar）
unar -o ./XC2101_extracted XC2101.LZH
# → ./XC2101_extracted/XC2101/BIN/DB.X

# 3. DB.XをHDSの\BINへコピー（hu68disk、エミュレータ停止中に実行）
tools-host/hu68disk/hu68disk copy disk/SYSTEM_HD.HDS ./arc/XC2101_extracted/XC2101/BIN/DB.X /BIN
```

`\BIN`に置くだけで追加設定なしに起動できる（環境変数等の設定は不要）。

### MCP アクション

起動例:
```
run_command("DB")           # ✅ 検証済み（バナー表示・ファンクションキーメニュー確認）
run_command("DB SAMPLE.X")  # 未検証
```

コマンド投入の基本パターン: `paste_text("<コマンド行>")` → `key(action="press", key="RETURN")`。
✅ ix68k検証済み（`Y/N`のみRETURN不要、1文字で即応答）。

| 操作 | MCP アクション | 検証 |
|------|---------------|------|
| デバッガを終了 | `paste_text("Q")` → `key(action="press", key="RETURN")` | ✅ |

### 検証メモ

- 2026-08-14: `XC2101.LZH`から`/BIN/DB.X`（83040バイト）を抽出し
  `disk/SYSTEM_HD.HDS`の`\BIN`へコピー。ix68k起動して以下を確認:
  - `run_command("DB")` → バナー`X68k Debugger version 3.00 Copyright 1987-1993
    SHARP/Hudson`（MPU/FPUエミュレーション行含む）とファンクションキーメニュー
    （C1/CU/CA/S1/SU/VOID/NWL/INS/N&CU/EOF）が表示され、正常に起動を確認。
  - `Q`コマンド＋RETURN → `C:\>`プロンプトへ正常復帰、終了を確認。
  - バナーの版表記は「X68k Debugger version 3.00」で、マニュアル出典
    （C compiler PRO-68K ver2.0 アセンブラマニュアル）記載の「XDebugger v2.00」とは
    異なる（配布元のXC2101.LZHがver2.1系のためと見られる）。
- コマンド一覧の内容は、XC20アセンブラマニュアル第6章（デバッガのコマンド）の要約。
  原本の`[?]`注記箇所（p.163 "dxception"の綴り、p.164のエラーメッセージ対応関係）は
  この操作マニュアルには影響しないため転記省略、詳細は参照元を参照。
- 2026-08-14（同日2セッション目）: `\BIN\ED.X`をデバッグ対象にロードし、ix68k（MCP経由）
  で約30コマンドの動作を検証。結果は各コマンド一覧表の「検証」列に反映済み。主な発見:
  - **`ME`/`MS`/`N`のサイズ指定子（および`N`のチェックポイント番号）はコマンド名に
    スペースなしで直接連結**する実装（`ME S 3000 12`は`Bad parameter.`、
    `MES 3000 12`が正しい）。マニュアルの`ME [<size>] ...`という角括弧表記だけでは
    この点が分かりません。
  - `Y/N`ポーズはRETURN不要、1文字入力のみで即座に応答します。
  - `¥`（コマンドライン繰り返し）は単体実行で`Command error.`となり動作せず
    （原因未特定、半角`\`でも同様）。ただし`:`区切りの一部（`D:L:Y/N:¥`のような形）
    としての動作は未検証のため、この結果だけで機能自体が壊れていると断定はできません。
  - `R@`/`W@`（ディスク物理リード/ライト）は実ディスクを直接破壊しうるため、
    テストは意図的に見送いました。
  - `H`（オンラインヘルプ）の出力から、マニュアル（v2.00）には無い
    `XI`/`XM`/`XFPCP`/`XDIS`/`XFX`/`XFP`コマンドがこのv3.00版に追加されていると判明
    （機能詳細・実地動作は未検証、存在の確認のみ）。
  - 検証で作成した一時ファイル（`TESTOUT.TXT`/`CMDLOG.TXT`/`TESTMEM.BIN`、いずれも
    `\BIN`）は検証後に`DEL`で削除済み。
