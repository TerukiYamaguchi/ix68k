# SYS.X

> Human68kシステムファイルを指定ドライブにコピー。システムディスク作成用。

---

## リファレンス（一次資料要約）

### 起動・コマンドラインオプション

書式:

```
SYS <d:>
```

カレントドライブのシステムファイル（属性 "S"）を指定ドライブにコピーし、システムディスクを作成します。コピー先ディスクは事前にFORMATコマンドでフォーマット済みで、かつ以下のいずれかを満たしていなければなりません：

- ブランクディスク（ファイル/ディレクトリなし）
- 既にシステムファイルが存在するディスク（バージョン更新時）

成功時メッセージ：`HUMAN®SYS / システムの転送を終了しました`

ファイルが連続FAT配置されていない場合は警告が表示されますが、HUMAN.SYS以外なら問題ありません。HUMAN.SYSについて警告が出た場合は、ディスクを削除またはフォーマット後に再実行してください。

## ix68kでの利用

### MCP アクション

```
run_command("SYS B:")
```

### 検証メモ

- **検証: ix68k確認済み（2026-08-14）**。使い捨てテスト用SCSI HDD（`hu68disk mkfs`作成、
  `disk/SYSTEM_HD.HDS`本番は未使用）に対し、FD0(`HUMAN302.XDF`)起動状態から`SYS C:`を実行。
- 成功メッセージは**マニュアル記載と異なる実際の文言**を確認:
  `C:\HUMAN.SYS  は連続したFATに転送されました`
  （連続クラスタ配置になったことをメッセージ自体が明示している）
- **転送されるのはHUMAN.SYSのみ**（属性"S"のファイルだけが対象。COMMAND.Xは対象外）。
  `DIR C:`では0ファイル・使用量58K相当（HUMAN.SYSは属性"S"のためDIR一覧に出ない）と
  なることを確認し、`DIR C:\COMMAND.X`も0件でCOMMAND.Xが転送されていないことを確認しました。
  対して`FORMAT.X`の対話メニュー「領域確保」の「システム転送：する」は
  **HUMAN.SYSとCOMMAND.Xの両方**を転送する（`FORMAT.X.md`参照）。目的に応じて使い分けが必要です。
