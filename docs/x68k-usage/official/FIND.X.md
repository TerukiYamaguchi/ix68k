# FIND.X

> 指定した文字列を含む行をファイルから抜き出す外部フィルタコマンド。

---

## リファレンス（一次資料要約）

### 起動・コマンドラインオプション

書式:

```
FIND ［/V］ ［/C］ ［/N］ ［/L］ ［/F］ ＜文字列＞ ［＜ファイル名＞］
```

指定した文字列を含む行を抜き出して表示します。ワイルドカードで複数ファイルをまとめて
検索でき、パイプやリダイレクトを介したフィルタとしても使えます。

| オプション | 効果 |
|-----------|------|
| `/V` | 指定文字列を**含まない**行を表示する |
| `/C` | 一致行数・不一致行数・全行数だけを表示する（`/V`・`/N`・`/F`は無視される） |
| `/N` | 出力に行番号を付けない |
| `/L` | 検索時に英大文字・小文字を区別しない |
| `/F` | 一致した行の先頭にファイル名を表示する（ワイルドカード指定時のみ有効） |

実行例: `FIND /V "error" log.txt` / `FIND /C "TODO" *.txt` / `FIND /F "warn" *.log`
