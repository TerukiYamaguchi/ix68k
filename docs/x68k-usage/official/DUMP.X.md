# DUMP.X

> ファイルの内容を16進数とアスキー文字で並べて表示します。バイナリファイルの中身をコード
> 単位で見るのに使います。

---

## リファレンス（一次資料要約）

### 起動・コマンドラインオプション

書式:

```
DUMP ＜ファイル名＞［/＜開始アドレス＞［, ＜バイト数＞］］
```

表示は3列構成: 左＝ファイル先頭からの相対アドレス、中央＝バイト単位の16進表示、
右＝対応するアスキー文字（表示できない文字は`.`になる）。

開始アドレスとバイト数はどちらも既定で10進数として扱われるが、`X`を頭に付ければ
16進数として指定できます。

| パラメータ | 意味 |
|-----------|------|
| `<ファイル名>` | ダンプ対象のファイル |
| `/<開始アドレス>` | ダンプを始めるオフセット（既定は10進） |
| `<バイト数>` | 表示するバイト数（省略時はファイル末尾まで） |

実行例: `DUMP MSTFL.100` / `DUMP FILE.DAT /X100` / `DUMP FILE.DAT /0, 256`

制御キー:
- `CTRL+S`: 表示を一時停止
- `CTRL+C`: 表示を中断して終了
