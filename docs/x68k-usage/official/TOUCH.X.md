# TOUCH.X

> ファイルやボリューム名のタイムスタンプ（作成日時）を書き換えます。

---

## リファレンス（一次資料要約）

### 起動・コマンドラインオプション

書式:

```
TOUCH [/T <hh>:<mm>:<ss>] [/V|/S|/A] <ファイル名> [/D <yyyy>-<mm>-<dd>]
```

ファイル名にはワイルドカードが使えます。読み出し専用属性やシステム属性が付いたファイルは
対象にできません。`/T`・`/D`をどちらも省略すると現在の日時が設定されます。

| オプション | 効果 | 例 |
|-----------|------|----|
| `/T <hh>:<mm>:<ss>` | 時刻を指定する（秒は偶数のみ扱えるため、奇数を指定すると補正される） | `TOUCH /T 12:00:00 TEST.TXT` |
| `/D <yyyy>-<mm>-<dd>` | 日付を指定する（年は1980〜2079、または2桁表記で80〜99=1980年代、00〜79=2000年代として解釈。月1〜12・日1〜31） | `TOUCH /D 90-07-23 TEST.TXT` |
| `/V` | 対象をボリューム名にする | - |
| `/S` | 対象をサブディレクトリにする | - |
| `/A` | ファイル・ボリューム・サブディレクトリすべてを対象にする | - |

## ix68kでの利用

### MCP アクション

```
run_command("TOUCH TEST.TXT")
run_command("TOUCH /D 90-07-23 /T 12:10:20 TEST.TXT")
```
