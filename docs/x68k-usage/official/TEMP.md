# TEMP

> アセンブラ・コンパイラ等が使う中間（テンポラリ）ファイルの保存先ディレクトリを設定・表示します。

---

## リファレンス（一次資料要約）

### 起動・コマンドラインオプション

書式:

```
TEMP [[<d:>]<パス名>]
```

引数なしで実行すると現在の設定を表示します。パス名を指定するとそこが以後の中間ファイル
置き場になります。アクセス速度は「RAMディスク > ハードディスク > フロッピーディスク」の
順なので、速いドライブを指定するほどビルド等の処理が速くなります。RAMディスクを使う場合は
`CONFIG.SYS`にデバイスドライバ`RAMDISK.SYS`を組み込んでおく必要があります。

| 用途 | コマンド例 |
|-----|-----|
| 保存先を設定する | `TEMP A:\TMP` |
| 現在の設定を表示する | `TEMP` |

---

## ix68kでの利用

### MCP アクション

```
run_command("TEMP A:\\TMP")
```
