# FC.X

> 2つのファイルの中身を比較し、差分を表示します。修正確認やテキストの突き合わせに使います。

---

## リファレンス（一次資料要約）

### 起動・コマンドラインオプション

書式:

```
FC ＜ファイル名1＞ ＜ファイル名2＞ ［/A］ ［/B］ ［/W］ ［/C］ ［/n］ ［/T＜タブカラム＞］ ［/L＜最大行数＞］ ［/＜一致行数＞］
```

比較モード（片方のみ指定可）:

| オプション | 効果 |
|-----------|------|
| `/A` | 行単位のアスキー比較を行う |
| `/B` | バイト単位のバイナリ比較を行う |

モードを省略した場合はアスキー比較になるが、拡張子が`.X` `.R` `.Z` `.SYS` `.O` `.A`の
いずれかであれば自動的にバイナリ比較へ切り替わる。

処理オプション:

| オプション | 効果 |
|-----------|------|
| `/W` | 連続する空白・タブを1つに圧縮してから比較する |
| `/C` | 英大文字・小文字の違いを無視する |
| `/n` | 出力に行番号を付ける |
| `/T<タブカラム>` | タブをスペースに展開する（`2`/`4`/`8`/`16`から指定） |
| `/L<最大行数>` | 比較する最大行数を指定する |
| `/<一致行数>` | 差分区間の終わりと判定する連続一致行数（1〜9、既定3） |

出力形式（アスキー比較時）:

```
+++++<ファイル名1>
<一致している部分の最後の1行>
<相違点>
...
+++++<ファイル名2>
...
```

出力形式（バイナリ比較時）:

```
アドレス        ファイル1  ファイル2
XXXXXXXX：      YY         ZZ
```

バイナリ比較は1バイトでもずれると、そこから先はすべて不一致として扱われる点に注意。

## ix68kでの利用

### MCP アクション

```
run_command("FC FILE1.TXT FILE2.TXT /A")
```
