# FASTIO.X

> ディスクI/Oの常駐キャッシュドライバ。読み書きしたセクタをメモリ上のバッファに保持し、
> 同じ領域への再アクセスを高速化します。

---

## リファレンス（一次資料要約）

### 起動・コマンドラインオプション

書式:

```
FASTIO ［キャッシュバッファ容量］［パラメータ］
```

コマンドラインからも `CONFIG.SYS` の `DEVICE=` からも常駐でき、常駐後は再度 `FASTIO` を
実行することで一部パラメータを変更できる（下表「常時変更可」の列を参照）。パラメータは
「初回常駐時のみ指定可能」「常駐後も再指定して変更可能」「常駐状態の照会・解除専用」の
3グループに分かれます。

サイズ・量を指定するパラメータ（新規常駐時のみ有効）:

| パラメータ | 意味 | 単位 |
|-----------|------|------|
| `-b 数値` | キャッシュバッファのサイズ | KB |
| `-p 数値` | 先読みするセクタ数 | セクタ |
| `-s 数値` | 連続転送用バッファのサイズ | KB |
| `-k 数値` | オートロックする範囲 | セクタ |

動作モードを切り替えるパラメータ（新規常駐時・常駐後の再指定どちらでも有効）:

| パラメータ | 効果 |
|-----------|------|
| `-d` | ディレクトリ領域のキャッシュを優先する |
| `-f` | FAT領域のキャッシュを優先する |
| `-l` | 現在のキャッシュ内容をロックして保持する |
| `-w` | ライトバック（遅延書込み）にする |
| `-x` | IOCS経由のディスクアクセスをエラー扱いにする |

上記のうち登録時のデフォルトに関するもの:

| パラメータ | 効果 |
|-----------|------|
| `-t` | ライトスルーにする（既定の動作） |
| `-u` | キャッシュロックを解除する |

常駐状態の照会・解除専用（常駐中のインスタンスに対してのみ意味を持つ）:

| パラメータ | 効果 |
|-----------|------|
| `-n` | 優先順位を指定しない |
| `-i` | 簡易なキャッシュ状態を表示する |
| `-v` | より詳細な状態を表示する |
| `-r` | 常駐を解除する |

キーボードから `CTRL+E` を押すとバッファがクリアされる（この動作はFASTIO/FASTOPEN/
FASTSEEKの3ドライバ共通）。

### 使用上の注意

- 複数の高速化ドライバ（FASTIO/FASTSEEK/FASTOPEN）を併用している場合、解除時は
  常駐させた順と逆順に解除する必要がある
- X68030シリーズ以外の機種では、これらのドライバを常駐させた後に`FDDEVICE`を
  常駐させることができなくなる
