# SCREEN

> ディスプレイ画面のモード（解像度・グラフィック色数・表示内容）を設定します。

---

## リファレンス（一次資料要約）

### 起動・コマンドラインオプション

書式:

```
SCREEN [<画面サイズ>, [<グラフィックモード>] , [<表示モード>]]
```

3つの数値パラメータをカンマ区切りで指定します。全部省略すると`SCREEN 0,0,0`と同じ扱いに
なり、一部だけ省略した場合はその項目に前回設定した値がそのまま使われます。

画面サイズ:

| 値 | 内容 |
|---|------|
| 0 | 横96文字（グラフィック768×512ドット） |
| 1 | 横64文字（グラフィック512×512ドット） |

グラフィックモード（画面サイズが1のときは2・3を指定できない）:

| 値 | 内容 |
|---|------|
| 0 | グラフィックなし |
| 1 | グラフィック16色 |
| 2 | グラフィック256色（画面サイズ0のときのみ） |
| 3 | グラフィック65536色（画面サイズ0のときのみ） |

表示モード（グラフィックモードが0のときは1・3を指定できない）:

| 値 | 内容 |
|---|------|
| 0 | テキストのみ表示 |
| 1 | テキスト＋グラフィック表示（グラフィックモード0では無効） |
| 2 | テキスト＋スプライト表示 |
| 3 | テキスト＋グラフィック＋スプライト表示（グラフィックモード0では無効） |

例えば`SCREEN 1,2,1`のあとに`SCREEN ,,3`を実行すると、先頭2つの値（画面サイズ=1、
グラフィック=2）は前回設定のまま引き継がれ、表示モードだけ3に変わる。

### 使用上の注意

- 3つのパラメータの区切りは必ずカンマにする
- グラフィック画面用のメモリをRAMディスクとして使っている場合、グラフィックモードは
  0以外に変更してはいけません。0以外を指定するとRAMディスクの内容が壊れる
- 万一RAMディスクを壊してしまった場合は、グラフィックモード0でSCREENを実行してから
  `FORMAT`で該当ドライブを再フォーマットする

```
run_command("SCREEN 0,1,1")
```
