# PROCESS.X

> プロセスの情報を表示します。

---

## リファレンス（一次資料要約）

### 起動・コマンドラインオプション

書式:

```
PROCESS [/A|/B]
```

現在動いているプロセスのメモリ割り当て状況を一覧表示します。バックグラウンドプロセスや
全プロセスの情報を見るには、あらかじめ`CONFIG.SYS`に`PROCESS`の設定が必要。表示内容には
PSP ID・プロセス管理ID・プログラム名・実行モード（16進数、スリープ中は`=`表示）・
スリープ残り時間・レジスタ値・プロセス間通信バッファの位置と長さが含まれます。

| オプション | 効果 |
|-----------|------|
| `/A` | バックグラウンドプロセスも含めた全プロセスの情報を表示する |
| `/B` | バックグラウンドプロセスの情報だけを表示する |

---

## ix68kでの利用

### MCP アクション

```
run_command("PROCESS")
run_command("PROCESS /A")
```
