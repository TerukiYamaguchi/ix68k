# RESTORE.X

> BACKUP コマンドでバックアップされたファイルを復旧します。

---

## リファレンス（一次資料要約）

### 起動・コマンドラインオプション

書式:

```
RESTORE <fd:> <hd:> [<パス名>] [/S] [/P] [/B:<日付>] [/A:<日付>] [/E:<時刻>] [/L:<時刻>] [/N]
```

`<fd:>`はバックアップ元のフロッピーディスク、`<hd:>`は復旧先のハードディスクを指します。
`<パス名>`を指定すると、そのディレクトリ配下だけが復旧対象になります。

引数なし（`RESTORE`のみ）で起動するとメニュー画面になり、「サブディレクトリもリストア」
「指定パスだけリストア」「ユーティリティ終了」から選びます。選択後はドライブ・ディレクトリを
指定し、必要なら変更日時での絞り込み条件を設定してから「リストア開始」を実行します。

コマンドライン指定時に使えるスイッチ:

| スイッチ | 効果 |
|---------|------|
| `/S` | サブディレクトリも含めて復旧する |
| `/P` | 不可視属性や読み取り専用属性のファイルを復旧する前に確認を求める |
| `/B:<日付>` | 指定日付以前に更新されたファイルだけを復旧する |
| `/A:<日付>` | 指定日付以降に更新されたファイルだけを復旧する |
| `/E:<時刻>` | 指定時刻以前に更新されたファイルだけを復旧する |
| `/L:<時刻>` | 指定時刻以降に更新されたファイルだけを復旧する |
| `/N` | 復旧先にまだ存在しないファイルだけを復旧する |

## ix68kでの利用

### MCP アクション

```
run_command("RESTORE")
```
