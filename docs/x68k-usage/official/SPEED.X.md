# SPEED.X

> RS-232Cインターフェイスの通信パラメータ設定。対話メニューまたはコマンドライン引数で設定できます。

---

## リファレンス（一次資料要約）

### 起動・コマンドラインオプション

書式:

```
SPEED [<パラメータ>]
```

本体内蔵、または増設ボード上のRS-232Cポート（AUX0〜AUX5）の通信条件を設定します。
引数を何も付けずに実行すると、対話式の設定メニューが開きます。

指定できるパラメータと選択肢:

| 項目 | 選べる値 |
|-----------|--------|
| ボーレート | `19200` / `9600` / `4800` / `2400` / `1200` / `600` / `300` / `150` / `75` |
| データ長 | `B8` / `B7` / `B6` / `B5`（ビット数） |
| パリティ | `PN`（なし） / `PE`（偶数） / `PO`（奇数） |
| ストップビット数 | `S1` / `S1.5` / `S2` |
| フロー制御方式 | `XON`（ソフトウェア） / `RTS`（ハードウェア） / `NONE`（なし） |

---

## ix68kでの利用

### MCP アクション

```
run_command("SPEED 9600 B8 PE S1 NONE")
```
