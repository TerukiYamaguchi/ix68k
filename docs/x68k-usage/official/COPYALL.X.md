# COPYALL.X

> ファイルおよびディレクトリを選択的にコピーします。異種ディスク間コピー・新規ファイルのみコピー・サブディレクトリごとコピーが可能で、部分的な更新バックアップに向きます。

---

## リファレンス（一次資料要約）

### 起動・コマンドラインオプション

書式:

```
COPYALL [/D] [<d1:>] [<パス名1>] <ファイル名1> {<d2:>|<パス名2>} [/T|/N] [/V] [/U] [/S]
```

コピー先のディスクが満杯になった場合はメッセージを表示してディスク交換を待ちます。

| オプション | 効果 |
|-----------|------|
| `/D` | サブディレクトリの中身をコピーせず、指定パス直下のファイルのみコピーする（無指定時は既定でサブディレクトリも同名ディレクトリを作りながら再帰的にコピーする） |
| `/T` | コピー元の方が新しいファイル、またはコピー先にまだ存在しないファイルだけをコピーする（`/N`とは併用不可） |
| `/N` | コピー元の方が新しいファイルだけをコピーします。コピー先に存在しないファイルはコピーされない（`/T`とは併用不可） |
| `/V` | 実際にはコピーを実行せず、コピー対象となる動作だけを表示する |
| `/U` | コピー元のファイル名に含まれる英小文字を、コピー先では英大文字に統一する |
| `/S` | `HUMAN.SYS`などのシステムファイルをコピー対象から除外する |

実行例:

```
COPYALL /D A:\*.* B:
COPYALL /T A:\*.* B:
COPYALL /T/U A:\*.* B:
```
