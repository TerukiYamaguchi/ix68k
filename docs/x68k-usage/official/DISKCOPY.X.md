# DISKCOPY.X

> フロッピーディスク1枚まるごとのコピー・内容比較。引数なしならメニュー画面、引数ありなら
> コマンド一発で実行できます。

---

## リファレンス（一次資料要約）

### 起動・コマンドラインオプション

書式:

```
DISKCOPY ［＜d1：>］［＜d2：>］［/V］
```

引数なしで起動するとメニュー画面が開き、機能（コピー／比較）・ドライブを対話的に選んで
実行します。コマンドラインで直接ドライブとオプションを渡せば、その場でコピーまたは比較が
始まる。

| オプション | 意味 |
|-----------|------|
| `<d1:>` | コピー元（比較モードでは比較元）のドライブ |
| `<d2:>` | コピー先（比較モードでは比較先）のドライブ |
| `/V` | コピーではなく内容の比較照合を行う |

実行例:

```
DISKCOPY A: B:           # AからBへコピー
DISKCOPY A: B: /V        # AとBの内容を比較
```

### 制限事項

- 同一ドライブ同士は指定できない
- コピー元とコピー先でディスク種別が異なる場合は実行できない
- コピー先がライトプロテクトされている場合は実行できない
- コピー先は事前にフォーマット済みである必要がある
- ハードディスク同士のコピーも可能だが、コピー先の容量がコピー元以上であることが必須
