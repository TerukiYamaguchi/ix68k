# SWITCH.X

> SRAM（メモリスイッチ）の内容を設定するコマンド。RS-232C・メモリ・ブート装置・テキストパレット等を変更できます。引数なしで対話メニュー、引数付きで即時設定。

---

## リファレンス（一次資料要約）

### 起動

```
SWITCH [キーワード=<値> ...]
```

引数を付けずに起動すると対話式のメニュー画面になります。キーワードと値を引数で渡すと、
メニューを経由せずその場で設定を反映して終了します。

### メニュー画面の操作

メニューは、設定項目（キーワード）ごとに「現在値」と「選べる値の範囲」を並べて表示する
一覧画面になっています。

| キー | 動作 |
|------|------|
| `↑` / `↓` | 項目間でカーソルを移動する |
| `RETURN` | カーソル位置の項目をパラメータ入力欄へ切り替える |
| パラメータ入力欄での `スペース`／`↑` | 値を1段階進める |
| パラメータ入力欄での `↓` | 値を1段階戻す |
| `ESC`（項目一覧側） | 変更を反映せずに終了する |
| `ESC`（パラメータ入力欄） | 編集前の値に戻して項目一覧側へ戻る |

設定を反映して終了するには、項目一覧の最後にある「終了」へカーソルを合わせて`RETURN`を
押します。確認メッセージが表示されるので、続けて何かキーを押すと保存されます。

| 操作 | キー手順 | 検証 |
|------|---------|------|
| 変更を反映せず終了する | `ESC` | ✅ |
| カーソルを下へ移動する | `↓` | ✅ |
| カーソルを上へ移動する | `↑` | ✅ |
| パラメータ入力を開始する | `RETURN` | ✅ |
| パラメータ入力を取り消す | `ESC` | ✅ |
| 値を1段階進める | `スペース` または `↑` | ✅ |
| 値を1段階戻す | `↓` | ✅ |
| 変更を反映して終了する | `↓`で「終了」へ移動 → `RETURN` → `RETURN` | 📖 |
| （項目一覧側での`→`／`←`の挙動） | パラメータ値の増減という報告あり | 📖・原本マニュアルには記載なし |

### 設定項目一覧

各項目にはコマンドライン引数用の1文字略称（`キーワード=値`の形）があります。

#### RS232C（略称 `R=`）— RS-232Cインターフェイス設定

| パラメータ | 値の例 |
|----------|--------|
| ボーレート | `9600` / `4800` / … 75〜19200の9段階 |
| データ長 | `8` / `7` / `6` / `5`（`BITS-8`等、または略称`B8`） |
| パリティ | `PN`（なし） / `PE`（偶数） / `PO`（奇数） |
| ストップビット数 | `S1` / `S1.5` / `S2` |
| フロー制御 | `Xon`（ソフト） / `Rts`（ハード） / `None` |
| ポート番号 | `AUX1`〜`AUX5`（増設ボード使用時に変更） |

例: `SWITCH R=9600 B8 PN S1 Xon`

#### MEMORY（略称 `M=`）— メインメモリ容量

`1024`〜`12288`（KB単位）。実装されている容量に合わせて設定します。

#### BOOT（略称 `B=`）— 起動デバイス

| 値 | 意味 |
|----|------|
| `STD` | 既定の優先順（FD0→FD1→SCSI0→SCSI1）で自動検索する |
| `2HD0`〜`2HD3` | 指定番号のFDDから起動する |
| `SCSI0`〜`SCSI7` | 指定IDのSCSI機器から起動する |
| `RAM` / `ROM` | SRAMまたはROMから起動する |

#### EJECT（略称 `E=`）— 電源OFF時のFD自動排出

`On`（自動排出する） / `Off`（しない）

#### OPT2KEY（略称 `O=`）— OPT.2キーの機能割り当て

`Tvctrl`（専用ディスプレイのTVコントロール用） / `Normal`（通常のキーとして使う）

#### CONTRAST（略称 `C=`）— 画面コントラスト

`0`〜`15`（数値が大きいほど明るい。`0`では表示が消える）

#### KANA（略称 `K=`）— かな入力の配列

`Jis`（JIS配列） / `Aiu`（50音順配列）

#### TV_CTRL — 電源OFF時のTV側の状態

`Tv`（TV画面表示を維持） / `Off`（TV電源も切る） / `$01`〜`$3F`（制御コードを直接指定）

#### LCD_MODE（略称 `L=`）— OPT.1+OPT.2起動の電卓の表示形式

`Lcd`（7セグメント風） / `Normal`（通常の文字）

#### SRAM（略称 `S=`）— SRAMの用途

| 値 | 意味 |
|----|------|
| `No_use` / `N` | ディスクにもプログラムにも使わない |
| `Ramdisk` / `R` | `SRAMDISK.SYS`組み込み時にRAMディスクとして使う |
| `Program` / `P` | プログラム用のワークエリアとして使う |

#### P0〜P8 — テキストパレットの初期値（略称 `Pn=`、例 `P1=$F83E`）

`$0000`〜`$FFFF`のGRB555ワード値。`G-$xx R-$xx B-$xx`の形式で表示されます。メニュー画面に
出てくるのはP0・P1・P2・P3・P4・P8（P5〜P7は非表示）。

#### XCHG（略称 `X=`、推定）— `¥`/`|`表示の切り替え

`0`〜`7`

#### WAIT_PRN（略称 `W=`）— プリンタのタイムアウト時間

32ビット値（目安として`$80000`が約5秒に相当）

#### FIRST_KY（略称 `F=`）— キーのオートリピート開始時間

`0`〜`15`。実際の時間は `200 + 100×n` ms

#### NEXT_KEY（略称 `N=`）— キーリピートの間隔

`0`〜`15`。実際の時間は `30 + 5×n²` ms

#### SCSI_ID（略称 `ID=`）— 本体のSCSI ID

`0`〜`7`（工場出荷時は`7`。内蔵SCSI機器のIDと重複しない値にする）

## ix68kでの利用

### MCP アクション

起動:

```python
run_command("SWITCH")          # メニューモード
run_command("SWITCH B=2HD0")   # コマンドラインモード（即時設定）
```

「メニュー画面の操作」の各操作に対応するMCPアクション:

| 操作 | MCP アクション | 検証 |
|------|---------------|------|
| 変更を反映せず終了する | `key(action="press", key="ESCAPE")`（SCANCODE 011B） | ✅ |
| カーソルを下へ移動する | `key(action="press", key="DOWN")`（SCANCODE 3E00） | ✅ |
| カーソルを上へ移動する | `key(action="press", key="UP")`（SCANCODE 3C00） | ✅ |
| パラメータ入力を開始する | `key(action="press", key="RETURN")`（SCANCODE 1D0D） | ✅ |
| パラメータ入力を取り消す | `key(action="press", key="ESCAPE")`（SCANCODE 011B） | ✅ |
| 値を1段階進める | `key(action="press", key="UP")`（SCANCODE 3C00） | ✅ |
| 値を1段階戻す | `key(action="press", key="DOWN")`（SCANCODE 3E00） | ✅ |
| 変更を反映して終了する | 上記の組み合わせ（`↓`移動→`RETURN`→`RETURN`） | 📖 |

### SRAMアドレスマップ（独自解析、P0〜P8）

テキストパレットP0〜P8のSRAM上のオフセットは、原本マニュアルには記載がなく、ix68kの
SRAMダンプとXEiJの実装を突き合わせて特定した（$ED0000相対）。

| 項目 | オフセット | アドレス | 初期値（XEiJ基準） |
|------|-----------|---------|-------------------|
| P0 | +$2E | $ED002E | $0000 |
| P1 | +$30 | $ED0030 | $F83E（水色） |
| P2 | +$32 | $ED0032 | $FFC0（黄色） |
| P3 | +$34 | $ED0034 | $FFFE（白） |
| P4 | +$36 | $ED0036 | $DE6C（薄緑灰） |
| P8 | +$38 | $ED0038 | $4022（濃紺） |

### 検証メモ

- 起動・ESC終了（変更なし）をix68k確認済み（2026-06-26）
- P8のSRAMアドレスをix68k確認: `$ED0038`に2バイト、初期値`$4022`（2026-06-26）
- パラメータ編集モードでは`↑`/`スペース`で値アップ、`↓`で値ダウン（例: RS232Cボーレート
  9600↔75）。キーワード欄では`↑↓←→`がカーソルを項目間移動させます。SCANCODEでix68k検証済み。
  `→`/`←`での値変更は原本マニュアルに記載がなく未検証
- **コマンドラインモード（引数付き起動）: ix68k検証済み（2026-08-14）**。`SWITCH B=SCSI0`を
  実行すると、メニュー画面を経ずに即座にコマンドプロンプトへ戻る。`$ED0018`（起動デバイス
  設定、2バイト）が書き換わることを`read_memory`で確認（実行前`$0000`→実行後`$A000`）。
  その後リセットすると実際にFD0を無視してSCSI0のHDDから起動することを確認
  （`FORMAT.X.md`のSCSI HDD検証と合わせて実施）。HDD起動時はそのHDDがドライブA:になる
  （`docs/ix68k-internals/mcp_debug_reference.md`「ドライブレター割り当て」の既知知見と一致）。
