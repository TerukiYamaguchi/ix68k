# MOVE.X

> ファイルを別のディレクトリに移動します。

---

## リファレンス（一次資料要約）

### 起動・コマンドラインオプション

書式:

```
MOVE {<d:> <パス名1>|<ファイル名1>} [<パス名2>]
```

指定したファイルを別ディレクトリへ移す（コピーではなく、移動後は元ファイルが削除される）。
ワイルドカードが使え、読み取り専用属性やシステム属性が付いたファイルは移動できません。
移動先ディレクトリはあらかじめ作成しておく必要があります。

移動先を省略するか`@`を指定すると、カレントディレクトリが移動先になります。ファイル名を
省略してディレクトリだけ指定した場合（`MOVE \TMP`のように）は、そのディレクトリ内の
全ファイルが移動先へ移されます。

スイッチは持ちません。

---

## ix68kでの利用

### MCP アクション

```
run_command("MOVE TEST.TXT \\TMP")
run_command("MOVE *.TXT \\TMP")
run_command("MOVE \\TMP\\TEST.TXT @")
```
