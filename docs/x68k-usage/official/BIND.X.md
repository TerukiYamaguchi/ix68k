# BIND

> 複数のXファイルを1つのオーバーレイXファイル（メモリ不足時に必要な部分だけを動的に
> 読み込むプログラム形式）へまとめる/編集するツール。

---

## リファレンス（一次資料要約）

### 起動・コマンドラインオプション

書式:

```
BIND [/O] <出力ファイル名> <ファイル名> [<ファイル名> …] [/D] [/L] [/X] [/T <パス名>]
```

新規にオーバーレイを組む以外に、既存のオーバーレイへのファイル追加・オーバーレイからの
ファイル取り出し・削除もできます。

| オプション | 効果 | 例 |
|-----------|------|----|
| `/O` | 新規にオーバーレイXファイルを作成する | `BIND /O TEST TEST1 TEST2` |
| `/L` | オーバーレイに含まれるXファイルの一覧を表示する | `BIND TEST /L` |
| `/D` | 指定ファイルをオーバーレイから削除する | `BIND TEST TEST2 /D` |
| `/X` | 指定ファイルをオーバーレイから単体ファイルとして取り出す | `BIND TEST TEST1 /X` |
| `/T <パス名>` | 一時ファイルの出力先を指定する（空き容量が必要） | `BIND TEST TEST2 /T C:\` |

オーバーレイ内の各ファイルには、結合した順に0から始まるモジュール番号が振られます。
呼び出し側は DOS コール `_exec` の MD（モード）上位バイトにこの番号を指定して実行する
（この呼び出し方法を使うには C Compiler PRO-68K が必要）。
