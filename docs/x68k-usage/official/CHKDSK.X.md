# CHKDSK

> ディスクのFAT領域・ディレクトリ領域を検査し、使用状況をレポートします。

---

## リファレンス（一次資料要約）

### 起動・コマンドラインオプション

書式:

```
CHKDSK [<d:>] [/A] [/V]
```

指定ドライブを検査し、ドライブ名・ボリュームラベル・作成日時、全容量とシステム/
ディレクトリ/ユーザーファイルそれぞれの使用量、空き容量を表示します。ファイルのデータ
ブロックがディスク上で不連続になっている場合は警告メッセージで知らせます。

| オプション | 効果 |
|-----------|------|
| `<d:>` | 検査対象ドライブ（省略時はカレントドライブ） |
| `/A` | 全ファイル・全ディレクトリを一覧表示し、使用セクタ範囲も報告する |
| `/V` | 全ファイル・全ディレクトリを一覧表示する（セクタ範囲は出さない） |

---

## ix68kでの利用

### MCP アクション

```
run_command("CHKDSK B: /A")
```
