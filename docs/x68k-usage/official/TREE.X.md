# TREE.X

> 指定ディレクトリ以下の構造をツリー形式で表示します。

---

## リファレンス（一次資料要約）

### 起動・コマンドラインオプション

書式:

```
TREE [/F] [<パス名>]
```

パス名を省略するとカレントドライブのルートディレクトリから表示します。システム属性・
不可視属性が付いたファイル/ディレクトリも区別せずすべて表示します。

| オプション | 効果 | 例 |
|-----------|------|----|
| `/F` | ディレクトリ構造に加え、各ディレクトリ内のファイル名も表示する | `TREE /F` |

---

## ix68kでの利用

### MCP アクション

```
run_command("TREE")
run_command("TREE \\TMP")
run_command("TREE /F")
```
