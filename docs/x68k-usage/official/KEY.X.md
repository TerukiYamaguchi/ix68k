# KEY.X

> ファンクションキーおよび各種キーのカスタマイズ。KEY.SYS ファイルの編集・登録を行う

---

## リファレンス（一次資料要約）

### 起動・コマンドラインオプション

書式:

```
KEY
```

引数なしで起動すると対話メニューになり、「ファイル更新（U）」「登録（L）」の2モードを
選べます。

**（U）ファイル更新モード:**

読み込む設定ファイル（既定`KEY.SYS`）と書き出す設定ファイル（既定`KEY.SYS`）を指定した
うえで、ファンクションキー（F1〜F10、Shift+F1〜F10）と特殊キー（ROLL UP/DOWN・INS・DEL・
カーソル各キー・HOME・HELP・CLR・UNDO）それぞれに割り当てる文字列を1つずつ入力していきます。
F1〜F10は半角31文字まで、それ以外のキーは半角5文字までしか入力できません。通常の文字列に
加えて、CR（`$0D`）はCTRL+ろ、BS（`$08`）はCTRL+む、特殊マーク（`$FE`）はCTRL+へで
埋め込めます。

**（L）登録モード:**

作成済みの`KEY.SYS`をシステムへ読み込ませ、設定を実際に有効化します。
