# ED.X

> Human68k 付属のスクリーンエディタ。ソースプログラム・テキストファイルの作成・編集に使用します。

---

## リファレンス（一次資料要約）

### 起動・コマンドラインオプション

書式:

```
ED [-A<パス>] [-E] [-H<幅>] [-L] [-M<行長>] [-S<モード>] [-T]
   [<d:>][<パス名>]<ファイル名>[.<拡張子>] ...（最大10ファイル）
```

| 項目 | 説明 |
|------|------|
| `<d:>` 省略 | カレントドライブが対象 |
| ファイル名省略 | `ED.$$$` が自動作成される → 終了後に `REN` または `COPY` で改名すること |
| 複数ファイル | スペース区切りで最大10ファイル同時編集可能 |

#### スイッチ一覧

| スイッチ | 引数 | 既定値 | 効果 |
|---------|------|-----------|------|
| `-A` | フルパス名 | ED.Xと同じディレクトリ | ヘルプファイルの場所を指定する |
| `-E` | なし | 非表示 | ファイル終端記号（EOF）を表示する |
| `-H` | `4`/`8`/`16`/`32`/`64` | `8` | 水平タブが画面上で何カラム分の幅になるか |
| `-L` | なし | 非表示 | 改行記号（↵）を表示する |
| `-M` | `128`/`256`/`512`/`1024` | `512` | 1行あたりの最大バイト数 |
| `-S` | `1`/`2` | `1` | 画面モード。`1`=96桁×30行、`2`=64桁×30行 |
| `-T` | なし | 非表示 | タブ記号（→…）を表示する |

### 終了操作

| 操作 | キー手順 | 検証 |
|------|---------|------|
| 全ファイルをセーブして終了 | `ESC` → `E` | 📖 |
| 全ファイルを保存せず終了 | `ESC` → `Q` → `Y` | ✅ |
| 現ファイルだけセーブして終了 | `ESC` → `X` | 📖 |
| 現ファイルだけ保存せず終了 | `ESC` → `K` | 📖 |

`ESC Q`は「全ファイルを編集前の状態のまま終了」の意味。変更が無ければ確認なしで
即座に終了するが、変更がある場合だけ「本当にエディタを終了してよろしいですか（Y/N）」
の確認が入る（2026-06-25ix68k確認）。

### コマンド一覧

コマンド系統は3種類:
- **CTRL系**: `CTRL`＋アルファベット1文字
- **ESC系**: `ESC`を押して画面左下に`*`が出た後、続けて次のキー
- **単独キー系**: ファンクションキー・専用キー単体

#### カーソル移動

| コマンド | 動作 |
|---------|------|
| `CTRL+E` / `↑` | 1行上 |
| `CTRL+X` / `↓` | 1行下 |
| `CTRL+S` / `←` | 1文字左 |
| `CTRL+D` / `→` | 1文字右 |
| `CTRL+A` | 1ワード左 |
| `CTRL+F` | 1ワード右 |
| `CTRL+B` | 行の右端↔左端トグル（行先頭にいれば行末へ、それ以外は行先頭へ） |
| `CTRL+P` | 行の右端に移動 |
| `CTRL+Q` | 行の左端に移動 |
| `CTRL+I` / `TAB` | 水平タブ分だけ右へ移動（右端に達したら改行） |
| `CTRL+R` / `ROLL DOWN` | 1ページ後ろ（下）へ |
| `CTRL+C` / `ROLL UP` | 1ページ前（上）へ |
| `CTRL+W` | 1行分ロールダウン |
| `CTRL+Z` | 1行分ロールアップ |
| `ESC B` / `F1` | ファイル先頭へ |
| `ESC N` / `F2` | ファイル末尾へ |
| `ESC <n>` | n行目へ移動（カラム位置は保持）。手順: `ESC` → 数値入力 → `RETURN` |
| `HOME` | 画面左上（ホームポジション）へ |

#### 挿入・上書き

| コマンド | 動作 |
|---------|------|
| `INS` | 挿入／上書きモードを切り替え（挿入モードでは画面に「挿入」、上書きモードでは「上書」と表示） |
| `CTRL+N` | 現在行の前に空行を1行挿入する |
| `CTRL+M` / `RETURN` | 改行する（挿入モードでは行が分割される） |
| `F10` | 現在行の内容を次の行にコピーして挿入する |

#### 削除

| コマンド | 動作 |
|---------|------|
| `CTRL+G` / `DEL` | カーソル位置の1文字を削除 |
| `CTRL+H` / `BS` | カーソルの直前の1文字を削除（バックスペース） |
| `CTRL+T` | カーソル位置の単語を削除 |
| `CTRL+Y` | 現在行を丸ごと1行削除する（`CTRL+L`で復帰可能） |
| `CTRL+U` | 行頭からカーソル直前までを削除 |
| `CTRL+K` | カーソル位置から行末までを削除 |

#### 検索

| コマンド | 動作 |
|---------|------|
| `F4` / `ESC N` | カーソルから文末方向へ検索。「前方検索文字列：」のプロンプトが出る |
| `SHIFT+F4` / `ESC S` | カーソルから文頭方向へ検索 |
| `F5` | `F4`で指定した文字列を続けて前方検索 |
| `SHIFT+F5` | 続けて後方検索 |

#### 置換

| コマンド | 動作 |
|---------|------|
| `ESC J` | 前方向に連続置換（1件ごとに確認あり） |
| `ESC L` | 後方向に連続置換（1件ごとに確認あり） |
| `ESC R` / `F3` | 前方向に連続置換（確認なし） |
| `ESC U` / `SHIFT+F3` | 後方向に連続置換（確認なし） |

#### ファイル読み込み・書き出し

| コマンド | 動作 |
|---------|------|
| `ESC Y` | 別のファイルを現在行の直前に挿入読み込みします。手順: `ESC` → `Y` → ファイル名 → `RETURN` |
| `ESC W` | 現在行からファイル末尾（または`F6`で指定した範囲）を別ファイルへ書き出します。手順: `ESC` → `W` → ファイル名 → `RETURN` |

#### カットバッファ

| コマンド | 動作 |
|---------|------|
| `F6` | 範囲指定を開始する（画面に「範囲指定」と表示） |
| `F7` | `F6`で指定した範囲をカットバッファへ移動する（元のテキストは削除される） |
| `F8` | `F6`で指定した範囲をカットバッファへコピーする（元のテキストは残る） |
| `F9` / `ESC G` | カットバッファの内容を現在行の直前に挿入する |
| `ESC <n> P` | 現在行からn行分をカットバッファへ格納する（元は削除）。手順: `ESC` → 数値 → `P` → `RETURN` |
| `ESC <n> G` | カットバッファの内容をn回挿入します。手順: `ESC` → 数値 → `G` → `RETURN` |

#### セーブ・終了

| コマンド | 動作 |
|---------|------|
| `ESC H` | 現在のファイルだけをセーブする（編集は継続） |
| `ESC E` | 全ファイルをセーブしてEDを終了する |
| `ESC X` | 現在のファイルだけをセーブしてEDを終了する |
| `ESC Q` | 全ファイルを保存せずに終了する（確認あり） |
| `ESC K` | 現在のファイルだけを保存せずに終了する |
| `ESC O` | 現在のファイルを編集前の状態に戻す（「再編集(Y/N)」の確認あり） |

#### その他

| コマンド | 動作 |
|---------|------|
| `CTRL+J` / `HELP` | ヘルプファイルを表示する |
| `CTRL+V` | コントロールコードを入力する（`CTRL+V`の後に大文字キーを押す） |
| `CTRL+O` | カーソル位置の文字の大文字・小文字を反転する |
| `ESC L` | 大文字/小文字変換モードの切り替え（画面右下に「大」/「小」表示） |
| `ESC M` | 改行記号（↵）の表示・非表示を切り替える |
| `ESC I` | タブ記号（→…）の表示・非表示を切り替える |
| `ESC C` | EDを抜けずにHuman68kコマンドを実行します。手順: `ESC` → `C` → コマンド → `RETURN` |
| `ESC T` | 現在のファイルのファイル名を変更します。手順: `ESC` → `T` → 新しい名前 → `RETURN` |
| `CLR` | ファイル終端記号（EOF）の表示・非表示を切り替える |
| `ESC @` | マクロを定義する（`ESC [@`〜`ESC @`の間の操作が記録される） |
| `UNDO` | 定義済みのマクロを実行する |

#### 複数ファイル編集

| コマンド | 動作 |
|---------|------|
| `ESC A` / `SHIFT+F6` | 次のファイルへ切り替える（正順） |
| `ESC D` / `SHIFT+F7` | 前のファイルへ切り替える（逆順） |
| `ESC F` | 新しいファイルを開きます。手順: `ESC` → `F` → ファイル名 → `RETURN` |
| `ESC V` | タグジャンプ（1カラム目に「ファイル名 `TAB` 行番号」を書いてから実行） |

## ix68kでの利用

### MCP アクション

起動:

```
run_command("ED MYFILE.TXT")
run_command("ED -S2 -M128 MYFILE.TXT")
```

終了操作は上の「終了操作」表と同じ「操作」名で対応する:

| 操作 | MCP アクション | 検証 |
|------|---------------|------|
| 全ファイルをセーブして終了 | `key(action="press", key="ESCAPE")` → `paste_text("E")` | 📖 |
| 全ファイルを保存せず終了 | `key(action="press", key="ESCAPE")` → `paste_text("Q")` → `paste_text("Y")` | ✅ |
| 現ファイルだけセーブして終了 | `key(action="press", key="ESCAPE")` → `paste_text("X")` | 📖 |
| 現ファイルだけ保存せず終了 | `key(action="press", key="ESCAPE")` → `paste_text("K")` | 📖 |
