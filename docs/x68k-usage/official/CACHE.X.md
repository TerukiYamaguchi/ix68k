# CACHE

> MC68030内蔵キャッシュメモリのON/OFF・対象範囲を切り替えます。

---

## リファレンス（一次資料要約）

### 起動・コマンドラインオプション

書式:

```
CACHE [on] [off] [def] [i] [d] [s]
```

キャッシュの有効/無効切り替えに加え、命令キャッシュ・データキャッシュを個別に指定でき、
現在の設定をS-RAMへ保存することもできます。

| オプション | 効果 |
|-----------|------|
| `on` | キャッシュメモリを有効にする |
| `off` | キャッシュメモリを無効にする |
| `def` | S-RAMに保存されている設定を読み込んで反映する（この場合`i`/`d`/`s`は無視される） |
| `i` | 命令キャッシュのみを操作対象にする |
| `d` | データキャッシュのみを操作対象にする |
| `s` | 現在の設定をS-RAMへ保存する |

---

## ix68kでの利用

### MCP アクション

```
run_command("CACHE on")
```
