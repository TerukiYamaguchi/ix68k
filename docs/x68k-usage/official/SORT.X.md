# SORT.X

> フィルタコマンド。標準入力のテキスト行をソート（並べ替え）して標準出力に出力。

---

## リファレンス（一次資料要約）

### 起動・コマンドラインオプション

書式:

```
SORT [/R] [/1] [/+n] [/T<タブサイズ>]
```

標準入力から1行ずつ読み込み、文字コード順（漢字はJISコード順）に並べ替えて標準出力へ
書き出します。ファイル名を直接指定する使い方はできず、リダイレクトかパイプで入出力を渡す
のが前提。

| オプション | 効果 |
|-----------|------|
| `/R` | 降順（Z→A）で並べ替える |
| `/1` | 大文字・小文字を区別せずに比較する |
| `/+n` | n桁目を比較の開始位置にする（省略時は先頭= 1桁目） |
| `/T<n>` | タブ1個を`<n>`桁分の空白として扱う（2/4/8/16のいずれか） |
