# PRINT.X

> バックグラウンド処理でファイルをプリンタに出力します。

---

## リファレンス（一次資料要約）

### 起動・コマンドラインオプション

書式:

```
PRINT [/W <n>] [/B <タブサイズ>] [<デバイス名>] [/L <n>] [/H <ヘッダ文字>|/T] [/F] [/N] [/K] [/P] [<ファイル名>]
```

印刷をバックグラウンドで行うには、事前に`CONFIG.SYS`へ`PROCESS=<プログラム数> <レベル>
<タイムスライス>`（例: `PROCESS=5 2 20`）を設定しておく必要があります。引数なしで実行すると、
現在の印刷状況（キューの状態）を表示するだけの照会モードになります。

| オプション | 効果 | 既定値 |
|-----------|------|--------|
| `/W <n>` | 1行あたりの文字数を指定 | 80 |
| `/B <タブサイズ>` | 水平タブの幅（2・4・8・16のいずれか） | 8 |
| `/L <n>` | 1ページあたりの行数を指定 | 66 |
| `/H <ヘッダ文字>` | ページ上部のヘッダ文字列 | 未指定時はファイル名 |
| `/T` | ヘッダを付けずに出力する | - |
| `/F` | ページの区切りをフォームフィードコードにする | 指定なしはCR/LF区切り |
| `/N` | 各行の先頭に行番号を付ける | - |
| `/K` | 実行中・待機中の印刷ジョブをすべて取り消す | - |
| `/P` | 印刷を一時中断・再開する | - |

## ix68kでの利用

### MCP アクション

```
run_command("PRINT /L 30 /W 72 A:CONFIG.SYS")
run_command("PRINT")
```
