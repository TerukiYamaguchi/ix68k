# TERM.X

> RS-232Cインターフェイスを使ったターミナル通信モードを開始します。

---

## リファレンス（一次資料要約）

### 起動・コマンドラインオプション

書式:

```
TERM [<ファイル名>]
```

文字コードはシフトJIS、改行コードはCR/LFを使います。通信条件（ボーレート等）自体は
`SPEED`コマンド側で設定しておきます。引数のファイル名はF8キーによる画面内容保存用の
保存先で、省略すると`TERM.S85`になります。

| 引数 | 用途 | 例 |
|-----------|------|----|
| `<ファイル名>` | F8キーで保存する画面内容の保存先を指定する | `TERM SCREEN.DOC` |

### 起動後の操作（対話型コマンド）

| 操作 | キー手順 | 検証 |
|------|---------|------|
| 全二重/半二重通信の切り替え | `F6`（画面表示がFull/Halfに変わる） | 📖 |
| プリンタ出力のオン/オフ切り替え | `F7`（画面表示がPrnoff/Prnonに変わる） | 📖 |
| 画面内容のファイル保存オン/オフ切り替え | `F8`（画面表示がWrtOff/WrtOnに変わる。保存中は新規内容を追記） | 📖 |
| OSコマンドの実行 | `F9`（画面表示がCommandに変わる） | 📖 |
| ターミナルモードの終了 | `F10`（画面表示がEndに変わる） | 📖 |

Human68k標準のエスケープシーケンスがそのまま使えます。

---

## ix68kでの利用

### MCP アクション

起動:

```
run_command("TERM SCREEN.DOC")
```

「起動後の操作」の各操作に対応するMCPアクション:

| 操作 | MCP アクション | 検証 |
|------|---------------|------|
| 全二重/半二重通信の切り替え | `key(action="press", key="F6")` | 📖 |
| プリンタ出力のオン/オフ切り替え | `key(action="press", key="F7")` | 📖 |
| 画面内容のファイル保存オン/オフ切り替え | `key(action="press", key="F8")` | 📖 |
| OSコマンドの実行 | `key(action="press", key="F9")` | 📖 |
| ターミナルモードの終了 | `key(action="press", key="F10")` | 📖 |
