# WHERE.X

> 指定したファイルをディレクトリツリー内から検索します。

---

## リファレンス（一次資料要約）

### 起動・コマンドラインオプション

書式:

```
WHERE [/A] [/F] {<d:>|<パス名>|<ファイル名>}
```

指定したファイルがディレクトリツリーのどこにあるかを検索し、見つかった場所の
ディレクトリパスを表示します。ドライブ名を省略するとカレントドライブ、パス名を省略すると
ルートディレクトリから検索を始めます。ワイルドカードも使えます。システム属性・不可視属性が
付いたファイルも検索対象に含みます。

| オプション | 効果 | 例 |
|-----------|------|----|
| `/A` | 全ドライブを対象に検索する（`<d:>`の同時指定は不可） | `WHERE /A TEST.TXT` |
| `/F` | ディレクトリパスに加えて見つかったファイル名自体も表示する | `WHERE /F *.TXT` |

---

## ix68kでの利用

### MCP アクション

```
run_command("WHERE TEST.TXT")
run_command("WHERE /F *.TXT")
```
