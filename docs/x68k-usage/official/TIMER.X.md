# TIMER.X

> 指定時刻にアラーム表示・ADPCM再生・テレビ制御を行う常駐型の時刻起動ツール。

---

## リファレンス（一次資料要約）

### 起動・コマンドラインオプション

書式:

```
(1) TIMER /ON ［＜番号＞］/OFF
(2) TIMER /A ＜時刻＞ ＜ファイル名＞
(3) TIMER /D ＜時刻＞ ＜ファイル名＞
(4) TIMER /T ＜時刻＞ ＜テレビ制御文字＞
(5) TIMER /L
(6) TIMER /K ＜番号＞
```

最大20件までの時刻指定イベントを登録でき、バックグラウンドで並行に動作します。使うには
事前に`CONFIG.SYS`へ`PROCESS =10 2 20`を追加してシステムを再起動しておく必要があります。

| オプション | 効果 | 例 |
|-----------|------|----|
| `/ON ［＜番号＞］` | 現在時刻をファンクションキー表示欄に出す（96桁モードなら時:分:秒、64桁モードなら時:分）。番号省略時はF10の位置に出る | `TIMER /ON1` |
| `/OFF` | 時刻表示を消す | `TIMER /OFF` |
| `/A ＜時刻＞ ＜ファイル名＞` | 指定時刻にADPCMファイルを再生する（15.6kHz、`$FF00`バイト以下） | `TIMER /A 12:00 A：¥PCM¥OHIRU.PCM` |
| `/D ＜時刻＞ ＜ファイル名＞` | 指定時刻にテキストファイルをウィンドウ表示する（約10秒間、60×25文字） | `TIMER /D 9:00 B：¥MEMO.DOC` |
| `/T ＜時刻＞ ＜制御文字＞` | 指定時刻にテレビ側を操作する（`OFF`/`CH1`〜`CH12`/`TV`/`COM`/`SP1`/`SP2`） | `TIMER /T 19:30 CH3` |
| `/L` | 登録済みのイベントを一覧表示する | `TIMER /L` |
| `/K ［＜番号＞］` | イベントを解除する（番号省略時は全件解除） | `TIMER /K 2` |

---

## ix68kでの利用

### MCP アクション

```
run_command("TIMER /ON")
run_command("TIMER /L")
```
