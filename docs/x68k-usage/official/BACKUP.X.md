# BACKUP

> ハードディスク上のファイルをフロッピーディスクへ退避します。

---

## リファレンス（一次資料要約）

### 起動・コマンドラインオプション

書式:

```
BACKUP <hd: [パス名]> [<ファイル名>] <fd:> [/S] [/A] [/D:<日付>] [/T:<時刻>]
```

パラメータなしで起動するとメニュー画面が開き、カーソルキーで対話的に条件を選べます。
パラメータを付けて起動すると、その場でバックアップを実行します。

| オプション | 意味 | 例 |
|-----------|------|----|
| `<hd:>` | バックアップ元（ドライブ・パス・ファイル名） | `BACKUP A:\ B:` |
| `<fd:>` | 出力先フロッピー（必須） | `BACKUP A:\ B: /S` |
| `/S` | サブディレクトリも対象に含める | `BACKUP A:\ B: /S` |
| `/A` | 既存のバックアップに追加する（古いファイルを消さない） | `BACKUP A:\ B: /A` |
| `/D:<日付>` | 指定日付以降に更新されたファイルだけを対象にする | `BACKUP A:\ B: /D:2026-01-01` |
| `/T:<時刻>` | 指定時刻以降に更新されたファイルだけを対象にする | `BACKUP A:\ B: /T:12:00` |

### 起動後の操作（対話型メニュー）

パラメータなしで実行した場合のメニュー操作:

1. カーソルキーで「サブディレクトリを含めない」「含める」を選ぶ
2. 対象ドライブ・ディレクトリ、日付/時刻の条件を設定する
3. 「バックアップ開始」を選んで実行する

## ix68kでの利用

### MCP アクション

```
run_command("BACKUP A:\\ B: /S")
```
