# CASE.X

> ファイル名中の半角英字の大文字/小文字を一括変換します。

---

## リファレンス（一次資料要約）

### 起動・コマンドラインオプション

書式:

```
CASE [/L|/U] [/D] [<パス名>|<ファイル名>]
```

指定したファイルの半角英字部分を大文字または小文字に統一します。読み出し専用属性・
システム属性の付いたファイルは対象外。ワイルドカードが使え、ファイル名を省略すると
カレントドライブのカレントディレクトリ内すべてが対象になります。

| オプション | 効果 | 例 |
|-----------|------|----|
| `/L` | 半角英字を小文字化する | `CASE /L *.X` |
| `/U` | 半角英字を大文字化する（既定） | `CASE /U *.X` |
| `/D` | ディレクトリ名も変換対象に含める | `CASE /D \BIN` |

---

## ix68kでの利用

### MCP アクション

```
run_command("CASE /U *.X")
```
