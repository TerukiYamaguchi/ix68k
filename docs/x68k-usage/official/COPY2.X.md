# COPY2.X

> ハードディスク上の大容量ファイルを複数枚のフロッピーディスクに分割して退避/復帰します。

---

## リファレンス（一次資料要約）

### 起動・コマンドラインオプション

書式:

```
COPY2 ［＜hd：>］［＜パス名＞］＜ファイル名＞［＜fd：>］          # 退避
COPY2 ［＜fd：>］＜ファイル名＞［＜hd：>］［＜パス名＞］／R     # 復帰
```

1枚に収まらない大きさのファイルを複数枚のフロッピーへ分割して退避でき、後から元通りに
復元できます。ドライブ・パス名を省略した場合はそれぞれカレントドライブ・カレントディレクトリが
対象になります。

退避したファイルは`COPY2`以外のコマンドでは扱えません。復帰時は、退避時と同じ順番で
フロッピーディスクを入れ替える必要があります。

### 起動後の操作（対話型メニュー）

パラメータなしで実行するとメニュー画面が開きます。

1. 「機能」で「退避」または「復帰」を選ぶ
2. 「送り側」で元ファイルのドライブ・ファイルを選ぶ
3. 「受け側」で宛先のドライブ・ディレクトリを選ぶ
4. 「実行」を選んで処理を開始する
5. ディスクが一杯になったら、画面の指示に従ってディスクを交換する

## ix68kでの利用

### MCP アクション

```
run_command("COPY2 A:\\TEST\\FILE.DAT B:")
run_command("COPY2 B:FILE.DAT A:\\TEST /R")
```
