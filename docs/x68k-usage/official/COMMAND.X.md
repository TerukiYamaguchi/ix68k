# COMMAND.X

> Human68kのコマンドプロセッサ。起動時に自動的に読み込まれるほか、`COMMAND`コマンドで
> 子プロセスとして明示的に起動することもできます。

---

## リファレンス（一次資料要約）

### 起動

書式:

```
COMMAND [/P] [/D] [/E:<環境エリアサイズ>] [/H:<ヒストリエリアサイズ>] [[/C] <文字列>]
```

パラメータなしで実行すると、Human68kのバージョンを表示したうえで子プロセスとして
COMMAND.Xを起動します。

| スイッチ | 効果 |
|---------|------|
| `/P` | 子プロセスから上位へ戻れないようにします。起動後に`AUTOEXEC.BAT`を自動実行する |
| `/D` | `/P`と同時指定で`AUTOEXEC.BAT`の自動実行を止めます。単独指定時は普通に子プロセスとして起動する |
| `/E:<n>` | `SET`コマンド用の環境エリア数を指定する（0〜255、1で256バイト、0で512バイト、既定0） |
| `/H:<n>` | `HIS`コマンド用のヒストリエリア数を指定する（0〜255、1で256バイト、0で512バイト、既定0） |
| `/C <文字列>` | 指定したコマンドを実行して終了します。`/C`自体は省略でき（`<文字列>`だけでも同じ動作）、`/C`を書いた場合その後に他のスイッチは置けない |

### 終了

子プロセスとして起動したCOMMAND.Xは`EXIT`コマンドで親プロセスに戻る。`/P`付きで
起動した場合は`EXIT`では上位に戻れません。

| 操作 | コマンド |
|------|---------|
| 子プロセスから親へ戻る | `EXIT` |

### エラーコード

バッチファイル実行中・`/C`付き実行時に返るエラーコード（`IF ERRORLEVEL`で参照可能）:

| コード範囲 | 意味 |
|-----------|------|
| `$00nn`（0〜255） | 外部コマンドのプロセス終了コード |
| `$01nn`（256〜511） | 外部コマンドが常駐終了した場合 |
| `$02nn`（512〜767） | CTRL+Cによる中断（下位バイトは不定） |
| `$03nn`（768〜1023） | ファンクションコールエラーによる強制終了（下位バイトはHuman68kのエラーコード） |
| `$04nn`（1024〜1279） | バッチ処理自体の実行時エラー（下位バイトは不定） |
| `$05nn`（1280〜1535） | 内部コマンド中のエラー。下位バイト内訳: `00`パラメータエラー、`01`ファイル読み出しエラー、`02`ファイル書き込みエラー、`03`ファイルが見つからない、`04`ディレクトリが満杯、`05`ディスク容量が満杯 |
| `$06nn`（1536〜1791） | 指定したコマンドが見つからない（下位バイトは不定） |

### リダイレクト

| 記号 | 意味 |
|------|------|
| `>` | 標準出力をファイル/デバイスへ書き出す（上書き） |
| `>>` | 標準出力をファイル末尾へ追記する |
| `<` | ファイルを標準入力として読み込む |

```
DIR > FILES.DAT        # ディレクトリ内容をファイルへ書き出す
DIR >> FILES.DAT       # 追記する
SORT < FILES.DAT       # ファイルを入力にしてソートする
SORT < FILES.DAT > FILES.SRT   # 入出力の両方をリダイレクトする
```

### パイプ

`|`（縦線1本）であるコマンドの出力を次のコマンドの入力へつなげます。フィルタとして使える
コマンドは`FIND`・`MORE`・`PR`・`SORT`。

```
DIR | SORT             # ディレクトリ内容をソートして表示
DIR | SORT | MORE      # さらに1画面ずつ表示
DIR | SORT > PRN       # ソート結果をプリンタへ送る
```

### マルチ処理

1行のコマンドラインに複数のコマンドを並べ、`||`（縦線2本）区切りで順に実行できます。

```
DIR || DATE || TIME
```

### CONFIG.SYSでの使用

`SHELL=`行でCOMMAND.Xのパスとスイッチを指定します。

```
SHELL=A:\COMMAND.X /P /E:2
```

### 内部コマンド一覧

COMMAND.Xに組み込まれた内部コマンド（各コマンドの詳細は`COMMAND.X_builtin.md`）:

| コマンド | 機能 |
|---------|------|
| `BREAK` | CTRL+Cチェック機能の設定 |
| `CD` / `CHDIR` | カレントディレクトリの変更・表示 |
| `CLS` | 画面消去 |
| `COPY` | ファイルのコピー・連結 |
| `CTTY` | 入出力デバイスの変更 |
| `DATE` | 日付の表示・設定 |
| `DEL` / `ERASE` | ファイルの削除 |
| `DIR` | ディレクトリ内容の表示 |
| `ECHO` | メッセージの表示・コマンド行表示設定 |
| `EXIT` | 子プロセスCOMMAND.Xから親プロセスへ戻る |
| `FOR` | コマンドの反復実行 |
| `GOTO` | バッチ処理の分岐 |
| `HIS` | ヒストリ行列の表示 |
| `IF` | 条件付きバッチ処理 |
| `MD` / `MKDIR` | ディレクトリ作成 |
| `MEMFREE` | 使用可能メモリの表示 |
| `PATH` | 外部コマンド検索パスの設定 |
| `PAUSE` | バッチ処理の一時停止 |
| `PROMPT` | プロンプトの設定 |
| `RD` / `RMDIR` | ディレクトリの削除 |
| `REM` | バッチ処理のコメント |
| `REN` / `RENAME` | ファイル名の変更 |
| `SET` | 環境文字列の設定 |
| `SHIFT` | バッチ処理のパラメータシフト |
| `TIME` | 時刻の表示・設定 |
| `TYPE` | ファイル内容の表示 |
| `VER` | Human68kバージョンの表示 |
| `VERIFY` | 書き込みベリファイのON/OFF |
| `VOL` | ボリューム名の表示・変更 |

> **注意**: `CACHE`・`KEY`・`MORE`はマニュアル上**外部コマンド**扱い（別途`.X`ファイルが必要）。

## ix68kでの利用

### MCP アクション

```python
run_command("COMMAND")           # 子プロセスとして起動
run_command("COMMAND /C DIR")    # DIR を実行して戻る
run_command("COMMAND /C TEST")   # TEST.BAT を呼び出して戻る
run_command("EXIT")              # 子プロセスから親へ戻る
```
