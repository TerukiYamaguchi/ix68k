# RECOVER.X

> 不良クラスタを含むファイル、ディレクトリ、またはディスク全体を修復します。

---

## リファレンス（一次資料要約）

### 起動・コマンドラインオプション

書式:

```
RECOVER [<d:> | <パス名>] [<ファイル名>]
```

引数なし（`RECOVER`のみ）で起動するとメニュー画面になり、次の3つから処理を選びます。

- **不良クラスタのあるファイルの修復**: 読み込みエラーになるファイルが対象。不良クラスタを
  読み飛ばしながら新しいファイルとして作り直す（読めなかった部分のデータは失われる）
- **不良クラスタのあるディレクトリの修復**: ディレクトリ自体が読み込みエラーになっている
  場合が対象。配下のファイルの一部は失われる
- **アクセスできないファイルの取り出し**: ディスク全体を走査し、階層ディレクトリ構造が
  壊れている場合に、その下にあったファイルをルートディレクトリへ引き上げる（ファイル名は
  仮のものになる）

いずれを選んでも、続けてドライブ・ディレクトリ・ファイルを指定する画面に移る。

コマンドラインから直接指定して非対話で実行することもできる:

```
RECOVER <パス名> <ファイル名>
```
指定ファイル内の不良セクタを読み飛ばして修復します。修復後、そのセクタは以降使用しない
よう記録されます。

```
RECOVER <d:>
```
ドライブ全体を修復します。階層ディレクトリが壊れている場合はルートディレクトリへ移動する
（メニュー版の「アクセスできないファイルの取り出し」と同じ動作）。
