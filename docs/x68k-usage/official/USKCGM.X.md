# USKCGM.X

> 外字（ユーザー定義文字）をドット単位で編集・登録・削除する対話型エディタ。

---

## リファレンス（一次資料要約）

### 起動・コマンドラインオプション

書式:

```
USKCGM
```

起動すると「更新ですか、登録ですか？＜U/L＞」と聞かれます。

- **U（更新）**: 外字データを新規作成・編集する
- **L（登録）**: 編集済みの外字ファイルをシステムに反映する

### 編集画面のキー操作

| キー | 機能 |
|-----|------|
| ROLLDOWN / ROLLUP | 編集対象を前後の外字コードへ切り替える |
| SPACE | ドットサイズを切り替える（16×16 ↔ 24×24） |
| HOME | カーソルを左上の基準位置へ戻す |
| CLR | 編集中のパターンを消去する |
| `0` | ドットの塗り方（白埋め/黒埋め）を切り替える |
| `5` | カーソル位置の色を反転させる |
| `1`〜`9` | 塗りながらカーソルを各方向へ移動する |
| `↑↓←→` | 塗らずにカーソルだけ移動する |
| F1 | 現在の外字をシステムへ登録する |
| F2 | コードを指定して外字を削除する |
| F3 | 登録済み外字の一覧を表示する |
| F4 | コードを指定して外字を呼び出し編集する |
| F5 | 外字ファイル（`USKCG.SYS`等）を読み込む |
| F6 | コードを指定してシステム標準の文字パターンを参照する |
| F7 | パターン全体を白黒反転する |
| F8 | パターン全体を90度回転する |
| F10 | 編集を終了する |

### 対応コード範囲

| コード範囲 | 種別 | 16×16時のサイズ | 24×24時のサイズ |
|----------|------|------|------|
| `$0000`〜`$7FFF` | JIS漢字コード（上下バイト逆順） | 32バイト | 72バイト |
| `$8000`〜`$EFFF` | シフトJIS漢字コード | 32バイト | 72バイト |
| `$F400`〜`$F5FF` | 半角外字 | 16バイト | 36バイト |

`$F400`〜`$F41F`と`$F500`〜`$F51F`はシステム用の特殊領域のため、通常のアプリからは
使用できません。
