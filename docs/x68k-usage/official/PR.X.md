# PR.X

> ファイル内容をページング整形します。プリンタ出力用に行幅・ページ行数・ヘッダ・タブサイズを指定可能です。

---

## リファレンス（一次資料要約）

### 起動・コマンドラインオプション

書式:

```
PR [/W<n>] [/L<n>] [/H<ヘッダ文字>] [/B<タブサイズ>] [/F] [/T] [/N] [<ファイル名> [<出力ファイル名>]]
```

ファイルをページ単位に区切って整形します。出力先ファイルを指定しなければ画面（標準出力）へ、
`PRN`を指定すればプリンタへ直接出します。標準入力を受けてフィルタとしても動作します。

| オプション | 効果 | 既定値 |
|-----------|------|--------|
| `/W<n>` | 1行あたりの文字数を指定 | 80 |
| `/L<n>` | 1ページあたりの行数を指定 | 66 |
| `/H<ヘッダ文字>` | ページ上部に出すヘッダ文字列 | 未指定時はファイル名 |
| `/B<タブサイズ>` | 水平タブの幅（2・4・8・16のいずれか） | 8 |
| `/F` | ページの区切りにフォームフィード（FF）を出す | 指定なしはCR/LF区切り |
| `/T` | ヘッダを付けずに出力する | - |
| `/N` | 各行の先頭に行番号を付ける | 付けない |

## ix68kでの利用

run_command("PR /W80 /L66 test.txt")
