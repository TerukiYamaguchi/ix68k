# FASTOPEN.X

> ディレクトリ検索の常駐キャッシュドライバ。ファイル名からのアクセス経路をメモリ上の
> バッファに憶えておき、以後の同じファイルへのアクセスを速くします。

---

## リファレンス（一次資料要約）

### 起動・コマンドラインオプション

書式:

```
FASTOPEN ［ネームバッファ数］［パラメータ］
```

コマンドラインからも`CONFIG.SYS`の`DEVICE=`からも常駐できます。

新規常駐時のみ有効なパラメータ:

| パラメータ | 効果 |
|-----------|------|
| `-b 数値` | 確保するネームバッファの個数を指定する |

新規常駐時・常駐後の再指定どちらでも有効なパラメータ:

| パラメータ | 効果 |
|-----------|------|
| `-c` | ファイル名の大文字・小文字を区別するようにする |
| `-l` | 現在のバッファ内容をロックする |
| `-x` | IOCS経由のディスクアクセスをエラー扱いにする |

上記のうち登録時のデフォルトに関するもの:

| パラメータ | 効果 |
|-----------|------|
| `-u` | バッファのロックを解除する |
| `-y` | IOCS経由のディスクアクセスでバッファを消去する |

常駐中のインスタンスに対してのみ意味を持つパラメータ:

| パラメータ | 効果 |
|-----------|------|
| `-z` | 全バッファを初期化する |
| `-i` | バッファの状態を表示する |
| `-v` | 詳細な状態を表示する |
| `-r` | 常駐を解除する |

キーボードから`CTRL+E`を押すとバッファがクリアされる（この動作はFASTIO/FASTOPEN/
FASTSEEKの3ドライバ共通）。

### 使用上の注意

- 複数の高速化ドライバ（FASTIO/FASTSEEK/FASTOPEN）を併用している場合、解除時は
  常駐させた順と逆順に解除する必要がある
- X68030シリーズ以外の機種では、これらのドライバを常駐させた後に`FDDEVICE`を
  常駐させることができなくなる

### MCP アクション

```
run_command("FASTOPEN -b 256")
```
