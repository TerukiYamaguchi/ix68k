# CONFIG.SYS

> 起動時に読み込まれるシステム構成ファイル。デバイスドライバの登録・バッファ数・並行
> 処理の可否などをディレクティブ（1行1設定のコマンド）で指定します。

起動ドライブのルートディレクトリに置いた`CONFIG.SYS`をHuman68kが起動時に読み込み、
記述されたディレクティブに従って動作環境を組み立てます。プレーンテキストなので`ED`等の
スクリーンエディタで編集できます。

---

## リファレンス（一次資料要約）

### ディレクティブ一覧

| ディレクティブ | 役割 |
|---------------|------|
| BELL | ビープ音として鳴らすPCMファイルの指定 |
| BREAK | CTRL+Cチェックの動作モード設定 |
| BUFFERS | ディスクバッファの個数・1個あたりの容量 |
| COMMON | COMMONファンクション用メモリ容量の指定 |
| DEVICE | デバイスドライバをシステムへ登録 |
| DIRSCH | ファイル検索の効率化 |
| ENVSET | 環境エリアの確保・環境ファイルの読み込み |
| EXCONFIG (CONFIGED) | CONFIG.SYS選択・修正ツールの起動条件 |
| FILES | 同時オープン可能なファイル数の上限 |
| KEY | キー定義ファイルの指定 |
| LASTDRIVE | 仮想ドライブを含めた最大ドライブ名 |
| PROCESS | 並行処理の制御パラメータ |
| PROGRAM | シェル起動前に走らせる常駐プログラム |
| SCSIDEV | SCSIデバイスドライバの登録可否 |
| SHARE | ファイル共有・排他ロックの設定 |
| SHELL | 起動時に使うコマンドプロセッサの指定 |
| TITLE | 起動時に表示するタイトルファイルの指定 |
| USKCG | 外字登録データファイルの指定 |
| VERIFY | 書き込み後ベリファイの有効/無効 |

### BELL

書式: `BELL=[<d:>][<パス名>]<ファイル名>`

エラー発生時・CTRL+G受信時に鳴らすビープ音として、ADPCM形式のPCMデータファイルを
指定します。ファイルサイズは64KBまでが対象で、それを超える部分は無視されます。指定が
なければビープ音自体が鳴りません。

### BREAK

書式: `BREAK=[ON|OFF|KILL]`

CTRL+C割り込みをどこでチェックするかを設定する（コマンドラインの`BREAK`コマンドと同じ設定項目）。

| 値 | 動作 |
|----|------|
| OFF | コンソール入出力・プリンタ出力時のみ有効（既定） |
| ON | 処理中を問わず常に有効（ディスクアクセス中の中断も可能） |
| KILL | CTRL+Cでは中断できません。本体のINTERRUPTスイッチのみが有効 |

### BUFFERS

書式: `BUFFERS=<ディスクバッファ数>[<バッファ容量>]`

ディスクバッファの個数（2〜99、既定20）と1個あたりの容量（1024〜32768バイト、既定
1024）を指定します。増やすほどディスクアクセスは速くなるが、`個数 × (容量 + 16)`バイト分
メモリを消費します。1セクタが1024バイトを超えるデバイスドライバを使う場合は、そのサイズ
以上の容量を指定する必要があります。

### COMMON

書式: `COMMON=<容量>`

プロセス間でデータを受け渡すコモンエリアの容量をKB単位で指定します。指定しないと
COMMONファンクション自体が使えない（呼び出すとエラーになる）。

### DEVICE

書式: `DEVICE=[<d:>][<パス名>]<ファイル名>[<オプション>]`

デバイスドライバをシステムへ登録し、起動時にメモリ常駐させます。1行につき1ドライバで、
複数行書けば複数登録できます。

例: `DEVICE=\SYS\PRNDRV.SYS`

代表的なデバイスドライバ:

| ドライバ | 用途 | 詳細 |
|---------|------|------|
| ASK68K.SYS | 日本語FEP入力 | オプションで辞書名・環境ファイル名を指定 |
| FDDEVICE.X | 2HD以外のFDD読み書き | 本書7.3参照 |
| FLOAT2.X / FLOAT3.X / FLOAT4.X | IEEE形式の数値演算 | 内蔵/CZ-6BP1/CZ-5MP1用 |
| HISTORY.X | ヒストリ・エイリアス・簡易バッチ機能 | 「ヒストリデバイスドライバ」節参照 |
| OPMDRV3.X | FM音源/ADPCM/MIDI | 本書7.4参照 |
| PRNDRV.SYS | プリンタ | 本書7.5参照 |
| RAMDISK.SYS | グラフィックRAM/メインメモリのRAMディスク化 | 本書7.6参照 |
| RSDRV.SYS | 増設RS-232Cボード | - |
| SRAMDISK.SYS | 内蔵バッテリバックアップRAMのRAMディスク化 | 本書7.6参照 |

### DIRSCH

書式: `DIRSCH=[ON|OFF]`

`ON`にすると、直前に見つけた位置からファイル検索を再開するようになる（毎回先頭から
探し直さない）ため、整列済みのファイル群を連続して検索する処理が速くなります。

### ENVSET

書式: `ENVSET=<環境エリア容量>[<d:>][<パス名>]<ファイル名>`

環境エリアを確保し、`環境変数名=値`を並べた環境ファイル（標準の名前は`STARTUP.ENV`）を
読み込んで環境変数を設定します。`SHELL`起動前に`PROGRAM`でプログラムを動かす場合や、
COMMAND.X以外をシェルに使う場合に必要になります。ファイル名を省略するとエリア確保のみ行います。

例:
```
PATH=A:\;A:\BIN;A:\UTL
WORK=A:\DOC
HELP=A:\HELP
```

### EXCONFIG (CONFIGED)

書式: `EXCONFIG=CONFIGED [<オプション>]`

起動時にCONFIG.SYSを選択・修正するツール「CONFIGED」を有効にする設定。`-K <キー名>`
（SHIFT/CTRL/OPT1/OPT2のいずれか、既定SHIFT）で、選択画面へ移るために押すキーを
指定します。指定キーを押しながら起動すると、起動ドライブの上位2階層にある
CONFIG.SYS/CONFIG.TMPの一覧が出て、カーソルキーで選んで編集できます。編集結果は
`CONFIG.TMP`として保存されます。編集画面の操作は矢印キー・DEL・BS・CLR・CTRL+K・
INS・ENTER・ESCのみで、漢字・ローマ字・コード入力はできません。

### FILES

書式: `FILES=<ファイル数>`

ファンクションコールで同時に開けるファイルハンドルの上限を指定する（5〜93、既定15）。

### KEY

書式: `KEY=[<d:>][<パス名>]<ファイル名>`

`KEY`コマンドで作ったキー定義ファイルの場所を指定します。省略時はルートディレクトリの
`KEY.SYS`を探し、それも無ければ既定のキー割り当てになります。

### LASTDRIVE

書式: `LASTDRIVE=<d:>`

`SUBST`コマンドやネットワークで使う仮想ドライブを含めた、使用する最大のドライブ名
（A〜Z）を指定します。省略時はZ。指定値が実際に接続されているドライブ数より小さい場合や
値が不正な場合は、実接続分の最後のドライブ名になります。

### PROCESS

書式: `PROCESS=<プログラム数> <レベル> <タイムスライス値>`

並行処理の制御パラメータを設定します。指定しないと並行処理はできません。

| パラメータ | 範囲 | 意味 |
|-----------|------|------|
| プログラム数 | 2〜32 | 同時に並行実行できるプログラム数 |
| レベル | 2〜255 | 実行間隔（値が小さいほど頻繁に切り替わる） |
| タイムスライス値 | 1〜100（ms） | 各プログラムに割り当てる実行時間 |

### PROGRAM

書式: `PROGRAM=[<d:>][<パス名>]<プログラム名>[<オプション>]`

`SHELL`起動前に走らせる常駐プログラム等を指定する（外部コマンドのみ指定可能、`COPY`等の
内部コマンドは指定できない）。使う場合は事前に`ENVSET`で環境エリアを確保しておく必要があります。

### SCSIDEV

書式: `SCSIDEV=[ON|OFF]`

SCSI ROM用のデバイスドライバを登録するかどうかを設定します。SCSIを使わないなら`OFF`に
すると起動が速くなります。

### SHARE

書式: `SHARE=<ファイル数> <ロック領域数>`

ネットワーク環境でファイルを共有する際の排他制御（ロック）を設定します。同時に扱える
ファイル数とロック領域数を指定します。

### SHELL

書式: `SHELL=[<d:>][<パス名>]<ファイル名>[<オプション>]`

起動時に使うコマンドプロセッサ（拡張子`.X`/`.R`）を指定します。省略時はCOMMAND.Xになります。

### TITLE

書式: `TITLE=[<d:>][<パス名>]<ファイル名>`

起動時に表示するタイトルファイルを指定します。省略時はルートディレクトリの`TITLE.SYS`が
あれば表示し、なければ何も表示しません。

### USKCG

書式: `USKCG=[<d:>][<パス名>]<ファイル名>`

外字登録用のデータファイルを指定します。省略時はルートディレクトリの`USKCG.SYS`があれば
登録し、なければ外字は登録されません。

### VERIFY

書式: `VERIFY=[ON|OFF]`

ディスクへの書き込み後に読み出して照合するかどうかを設定する（コマンドラインの
`VERIFY`コマンドと同じ設定項目）。`ON`にすると書き込みは遅くなるが、書き込み不良を
その場で検出できます。省略時はOFF。
