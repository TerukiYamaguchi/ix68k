# MORE.X

> 標準入力を1画面ずつ分割表示するフィルタコマンド

---

## リファレンス（一次資料要約）

### 起動・コマンドラインオプション

書式:

```
MORE ［＜ファイル名＞］
```

1画面分を出力するごとに画面下部へ`-more-`と表示していったん止まり、キーを押すと続きが
表示されます。これを標準入力が尽きるまで繰り返すページャ。

パイプ・リダイレクトの出力先として使うほか、ファイル名を直接引数に渡すこともできます。
ただしファイル名を指定した場合、同時にパイプから来たデータがあっても無視されます。

---

## ix68kでの利用

### MCP アクション

```
run_command("TYPE file.txt | MORE")
run_command("MORE largefile.txt")
```
