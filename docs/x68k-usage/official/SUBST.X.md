# SUBST.X

> 実ドライブ上のディレクトリを、別名の仮想ドライブとして参照できるようにします。割り当ての解除・一覧表示にも対応。

---

## リファレンス（一次資料要約）

### 起動・コマンドラインオプション

書式:

```
SUBST [/D] [/L] [<d1:> <パス名1>] [<d2:> <パス名2>] ...
```

ドライブ名とパス名の組を指定すると、そのパスを指定ドライブ名でアクセスできるようになります。
指定する2つの引数のうち、少なくとも一方はドライブ名である必要があります。

| オプション | 効果 | 例 |
|-----------|------|----|
| （オプションなし） | 仮想ドライブを割り当てる | `SUBST Z: A:\USR\SATO\DOC` |
| `/D` | 割り当てを解除する（ドライブ名を指定すればそのドライブのみ、省略時は全て） | `SUBST /D Z:` |
| `/L` | 現在の割り当て状況を一覧表示する（ドライブ名省略時は全ドライブ分） | `SUBST /L` |

SUBSTで割り当てた仮想ドライブに対しては、FORMATやDISKCOPYのような物理層に直接アクセスする
コマンドは使えません。同時に扱えるドライブ数の上限は`CONFIG.SYS`の`LASTDRIVE`設定に従います。

## ix68kでの利用

### MCP アクション

```
run_command("SUBST Z: A:\\USR\\DOC")
```
