# COMMAND.X 内部コマンド一覧

COMMAND.Xに組み込まれているため、外部ファイルなしでカレントドライブを問わず常に
実行できるコマンド群。

---

## リファレンス（一次資料要約）

### BREAK

```
BREAK [ON|OFF|KILL]
```

CTRL+Cの監視方法を切り替える。

| 引数 | 動作 |
|------|------|
| `ON` | システムの内部処理単位ごとにCTRL+Cを監視する（コンパイル処理中でも中断できる） |
| `OFF` | キーボード・画面・プリンタとの入出力時のみ監視する（既定） |
| `KILL` | CTRL+Cでは中断不可にする。中断には本体のINTERRUPTスイッチを使う |
| 省略 | 現在の設定を表示する（`break は <on/off/kill> です`） |

---

## ドライブ変更（<d:>）

```
<d:>
```

プロンプトの直後にドライブ名とコロンだけを入力すると、カレントドライブが切り替わる
（`CD <d:>`はカレントドライブを移動せず他ドライブのディレクトリだけを変更するもので、
これとは別）。

```
B:              # カレントドライブをA:からB:に変更
```

---

## CD / CHDIR

```
CHDIR [<d:>][<パス名>]
CD    [<d:>][<パス名>]
```

カレントディレクトリを変更・表示する。`<d:>`を付けると、カレントドライブを移動せずに
他ドライブ側のディレクトリだけを変更できる。パラメータを省略すると現在のカレント
ディレクトリを表示する。

```
CHDIR \SUB1\SEC1    # 絶対パスで指定
CHDIR ..\SEC2       # 相対パスで指定（..は1つ上の階層）
CHDIR               # 現在のディレクトリを表示
```

---

## CLS

```
CLS
```

テキスト画面の内容を消してカーソルを左上（ホームポジション）へ戻す。グラフィック画面は
そのまま変化しない。

---

## COPY

```
COPY [<d:>|<パス名1>|<ファイル名1>] [[<d:>|<パス名2>|<ファイル名2>]] [/V] [/Q] [/B]
```

ファイルのコピー、またはファイル同士の連結を行う。

| スイッチ | 効果 |
|---------|------|
| `/V` | コピー後に自動でベリファイする（その分遅くなる） |
| `/Q` | コピー対象のファイル名と確認メッセージを表示してから実行する |
| `/B` | バイナリファイルを連結する際に指定する |

---

## CTTY

```
CTTY <デバイス名>
```

標準入出力に使うデバイスを切り替える。

```
CTTY AUX    # キーボード/画面 → RS-232C(AUX)側へ切り替える
CTTY CON    # RS-232C側から入力してCON（キーボード/画面）へ戻す
```

---

## DATE

```
DATE [<yyyy>-<mm>-<dd>]
```

日付を表示・設定する。パラメータを省略すると現在日付を表示したまま入力待ちになる
（そのままEnterで変更なし）。

- 年: 1980〜2079（2桁で入力した場合、0〜79は2000〜2079、80〜99は1980〜1999として解釈）
- 月: 1〜12、日: 1〜31
- 区切り文字はハイフン（`-`）またはスラッシュ（`/`）

---

## DEL / ERASE

```
DEL  [<d:>][<パス名>]<ファイル名>
ERASE [<d:>][<パス名>]<ファイル名>
```

ファイルを削除する。ワイルドカードが使える。`*.*`を指定した場合のみ確認メッセージが出る。

---

## DIR

```
DIR [<d:>][<パス名>][<ファイル名>] [/N] [/L] [/T] [/R] [/P] [/W]
```

ディレクトリ内のファイル一覧を表示する。

| スイッチ | 効果 |
|---------|------|
| `/N` | 名前順（昇順）で並べる |
| `/L` | サイズ順（昇順）で並べる |
| `/T` | 更新時刻順（昇順）で並べる |
| `/R` | `/N`/`/L`/`/T`と併用して並び順を逆にする |
| `/P` | 1画面ぶん表示するごとに一時停止する |
| `/W` | 1行に4件（64カラムモードでは2件）並べたワイド表示にする。ファイル名のみ表示 |

---

## ECHO

```
ECHO [ON|OFF|<メッセージ>]
```

バッチ処理中のコマンド行表示のON/OFF切り替え、またはメッセージの表示に使う。

| 引数 | 動作 |
|------|------|
| `ON` | バッチ実行中の各コマンド行をそのまま画面に出す（初期設定） |
| `OFF` | コマンド行を画面に出さない |
| `<メッセージ>` | 指定した文字列を表示する（`ECHO OFF`中でも表示される） |
| 省略 | 現在のECHOモードを表示する |

---

## EXIT

```
EXIT
```

子プロセスとして起動されたCOMMAND.Xから、呼び出し元の親プロセスへ処理を戻す。`/P`付きで
起動した場合、`EXIT`では上位へ抜けられない。

---

## FOR

```
FOR %%<C> IN (<項目のセット>) DO <コマンド>   # バッチファイル中で使う場合
FOR  %<C> IN (<項目のセット>) DO <コマンド>   # コマンドラインへ直接入力する場合
```

`<項目のセット>`に含まれる要素の数だけ`<コマンド>`を繰り返し実行する。実行のたびに
変数`<C>`へ各要素が順番に代入される。`<項目のセット>`にはワイルドカードを使える。

```
FOR %%E IN (PROC.100 PROC.200) DO DUMP %%E
```

---

## GOTO

```
GOTO <ラベル>
```

バッチファイル中で`:<ラベル>`として定義した行へ処理をジャンプさせる。ラベルは8文字
以内で、定義側は先頭に`:`が必要（`GOTO`で参照する側は`:`を付けない）。対応するラベルが
見つからない場合は、そこでバッチファイルの実行が終わる。

---

## HIS

```
HIS [<開始行>[,<終了行>]] [/B]
```

これまでに実行したコマンドの履歴（ヒストリ行列）を表示する。

| 指定 | 表示内容 |
|------|---------|
| 省略 | 全履歴を新しい順に、行番号付きで表示する |
| `HIS 20,10` | 20行目から10行目までを表示する |
| `HIS 15` | 15行目だけを表示する |
| `/B` | 行番号を付けず制御文字もそのまま出力する（リダイレクトしてバッチファイル化する用途） |

```
HIS 20,10 /B > TEST.BAT    # 過去のコマンド列をバッチファイルとして保存する
```

---

## IF

```
IF [NOT] <条件> <コマンド>
```

指定した条件が成り立つときだけ`<コマンド>`を実行する。`NOT`を付けると条件を反転する。

| 条件の書式 | 意味 |
|----------|------|
| `<文字列1>==<文字列2>` | 2つの文字列が一致する場合（`==`の前後にスペースが必須） |
| `<数値>` | 数値が0以外の場合 |
| `ERRORLEVEL <数値>` | COMMAND.Xのエラーコードが`<数値>`以上の場合 |
| `EXITCODE <数値>` | COMMAND.Xのエラーコードが`<数値>`と一致する場合 |
| `EXIST <ファイル名>` | 指定したファイルが存在する場合 |

---

## MD / MKDIR

```
MKDIR [<d:>]<パス名>
MD    [<d:>]<パス名>
```

新しいディレクトリを作る。同名のファイルまたはディレクトリが既に存在する場合は作成できない。

```
MKDIR \SUB1         # ルート直下にSUB1を作る
MKDIR DOCS          # カレントディレクトリ下にDOCSを作る
```

---

## MEMFREE

```
MEMFREE
```

現在使用できるメモリ容量を表示する（RAMディスク・常駐プログラム・Human68k本体・
親プロセスが使っている分は除いたサイズ）。

---

## PATH

```
PATH [:][[<d:>]<パス名>[;[<d:>]<パス名>]...]
```

外部コマンドを探すディレクトリを設定する。複数指定する場合はセミコロン（`;`）で区切る。

| 入力 | 動作 |
|------|------|
| `PATH A:\BIN;B:\` | A:\BINとB:\を検索パスとして設定する |
| `PATH` | 現在のパス設定を表示する |
| `PATH ;` | パス設定を解除する |

---

## PAUSE

```
PAUSE [<コメント>]
```

バッチファイルの実行を一時停止し、`準備ができたら何かキーを押してください`と表示する。
`<コメント>`を付けるとそのメッセージも合わせて表示する。CTRL+Cを押すと中断するか確認する。

---

## PROMPT

```
PROMPT [<プロンプトテキスト>]
```

コマンドプロンプトの表示形式を変更する。省略すると既定の`X>`形式に戻る。テキスト中では
`$`に続けて以下の記号を書くと、対応する内容に置き換えられる。

| 記号 | 展開結果 |
|------|---------|
| `$N` | カレントドライブ名（大文字） |
| `$n` | カレントドライブ名（小文字） |
| `$D` | 現在の日付 |
| `$T` | 現在の時刻 |
| `$P` | カレントドライブ名＋カレントディレクトリ名 |
| `$V` | バージョン表示 |
| `$$` | `$`という文字そのもの |
| `$G` | `>`という文字 |
| `$L` | `<`という文字 |
| `$B` | `\|`という文字 |
| `$_` | 改行 |
| `$S` | 空白 |
| `$H` | バックスペース |
| `$E` | エスケープコード（`1Bh`） |

```
PROMPT $N$G    # 既定と同じ「A>」になる
PROMPT $P$G    # カレントパス付きの「A:\BIN>」になる
```

---

## RD / RMDIR

```
RMDIR [<d:>]<パス名>
RD    [<d:>]<パス名>
```

ディレクトリを削除する。中身が空でないと削除できない。

---

## REM

```
REM [<コメント>]
```

バッチファイル中にコメントを書くための行。実行しても何も起きない。コメント内で
使える区切り文字はスペース・タブ・カンマのみ。

---

## REN / RENAME

```
REN    <ファイル名1> <ファイル名2>
RENAME <ファイル名1> <ファイル名2>
```

ファイル名を変更する。ワイルドカードが使える。別ドライブへ移すことはできない。

---

## SET

```
SET [<名前>=[<文字列>]]
```

環境変数を設定・削除・一覧表示する。

| 入力 | 動作 |
|------|------|
| `SET TTY=X68000` | 環境変数TTYに「X68000」をセットする |
| `SET TTY=` | 環境変数TTYを削除する |
| `SET` | 現在設定されている全環境変数を表示する（PATHも含む） |

バッチファイル中では`%TTY%`のように`%名前%`と書けば参照できる。

---

## SHIFT

```
SHIFT
```

バッチ処理のパラメータを1つずつ前へずらす。`%1`に`%2`の値が、`%2`に`%3`の値が入る、
という具合に送られるため、10個以上のパラメータも扱えるようになる。ずらした結果
実パラメータが無くなった位置には空文字列が入る。

---

## TIME

```
TIME [<hh>:<mm>:<ss>]
```

時刻を表示・設定する。パラメータを省略すると現在時刻を表示したまま入力待ちになる
（そのままEnterで変更なし）。

- 時: 00〜23、分: 00〜59、秒: 00〜59（いずれも省略不可）

```
TIME 10:10:30    # コマンドラインで直接指定する
```

---

## TYPE

```
TYPE <ファイル名> [<ファイル名>...]
```

ファイルの中身をテキストとして表示する。複数指定すると順番に表示する。ワイルドカードが
使える。バイナリファイルは制御文字も記号として表示されてしまうため、その場合は`DUMP`
コマンドを使う。

---

## VER

```
VER
```

Human68kのバージョンを表示する（例: `Human68k version 3.02`）。

---

## VERIFY

```
VERIFY [ON|OFF]
```

ディスクへ書き込んだ直後に読み出して照合するかどうかを設定する。

| 引数 | 動作 |
|------|------|
| `ON` | 書き込み直後に読み出して照合し、不良セクタがあればすぐエラー報告する（書き込みは遅くなる） |
| `OFF` | 照合しない（既定） |
| 省略 | 現在の設定を表示する |

`CONFIG.SYS`の`VERIFY=`でも同じ設定ができる。

---

## VOL

```
VOL [<d:>] [<ボリュームラベル>/S|/C]
```

ディスクのボリュームラベルを表示・変更・削除する。

| 入力 | 動作 |
|------|------|
| `VOL A:` | ドライブAのボリュームラベルを表示する |
| `VOL A: MYDISK/S` | ドライブAのボリュームラベルを「MYDISK」に変更する |
| `VOL B: /C` | ドライブBのボリュームラベルを削除する |

> **注意**: 仮想ドライブにボリュームラベルを設定すると、実体側のディレクトリにも同じ
> ラベルが付く。そのディレクトリは`RMDIR`で削除できなくなるため、削除する前に先に
> ラベルを消してから仮想ドライブの設定を解除する必要がある。
