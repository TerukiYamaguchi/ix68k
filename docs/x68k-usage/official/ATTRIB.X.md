# ATTRIB

> ファイルの読み出し専用属性・不可視属性を設定/解除/表示します。

---

## リファレンス（一次資料要約）

### 起動・コマンドラインオプション

書式:

```
ATTRIB [+R|-R] [+H|-H] [<ファイル名>]
```

ファイル名を省略すると全ファイルの属性一覧を表示します。属性スイッチを付けずファイル名だけ
指定した場合は、そのファイル1つの現在の属性を表示します。

| オプション | 効果 | 例 |
|-----------|------|----|
| `+R` | 読み出し専用属性を付ける | `ATTRIB +R MSTFL.100` |
| `-R` | 読み出し専用属性を外す | `ATTRIB -R MSTFL.100` |
| `+H` | 不可視属性を付ける（`DIR`等の一覧に出なくなる） | `ATTRIB +H MSTFL.100` |
| `-H` | 不可視属性を外す | `ATTRIB -H MSTFL.100` |
| `/?` | ヘルプを表示する | `ATTRIB /?` |

属性一覧表示時に使われる記号:

| 記号 | 意味 |
|-----|------|
| A | アーカイブ（通常ファイル） |
| D | ディレクトリ |
| V | ボリュームラベル |
| S | システム |
| H | 不可視 |
| R | 読み出し専用 |

## ix68kでの利用

### MCP アクション

```
run_command("ATTRIB +R MSTFL.100")
```
