# ZP.R (ZP プレイヤー)

> [ZMUSIC.X](ZMUSIC.X.md)支援ツールのサンプルとして同梱される演奏制御プレイヤー。演奏データ（ZMD/ZMS/OPM）の再生・停止・チャンネルマスク・フェード等に加え、ジュークボックス機能・キーボードによるリアルタイム演奏制御（デバッグツール）を備えます。

---

## リファレンス（一次資料要約）

### 起動・コマンドラインオプション

書式:

```
ZP [-スイッチ[パラメータ]]...
```

スイッチ先頭の`-`は省略できる場合がある（演奏開始の`-P`のみ）。セットアップファイルは
`,`区切りで最大4つまで指定できます。演奏データファイル名の拡張子は省略可能で、省略時は
`.ZMD`→`.ZMS`→`.OPM`の順に自動検索される（セットアップファイルの拡張子は省略不可）。

演奏そのものを制御するスイッチ:

| オプション | 効果 |
|-----------|------|
| `[-P] <演奏データ>[,<setup1>,...,<setup4>]` | 演奏データ（省略時`.ZMD`→`.ZMS`→`.OPM`の順に検索）を最大4つのセットアップファイル（ADPCMコンフィグ／ZPD／MDD等）と一緒に読み込んで演奏します。演奏データを省略するとセットアップファイルだけ実行することもできる（ZPD/ADPCMコンフィグは演奏中でも実行でき、リアルタイム変更用に使える） |
| `-P<n1,n2,...>` | 演奏を開始します。トラック番号（1〜80）を指定するとそのトラックだけ、省略時は全トラック |
| `-S<n1,n2,...>` | 演奏を停止します。トラック番号を指定できる、省略時は全トラック |
| `-C<n1,n2,...>` | 演奏を再開します。トラック番号を指定できる、省略時は全トラック |

チャンネルの発音・マスクを操作するスイッチ:

| オプション | 効果 |
|-----------|------|
| `-E<n1,n2,...>` | 指定チャンネルだけを演奏する（他はマスクされる）。チャンネル番号は通常1〜25、PCM8独立チャンネルモードでは1〜32。省略で全マスク解除。`FM1`〜`8`/`ADPCM1`〜`8`/`MIDI1`〜`16`という書き方もできます。リアルタイムで変更可能 |
| `-M<n1,n2,...>` | 指定チャンネルをマスクする（他は通常通り演奏）。番号範囲・表記は`-E`と同じ。省略で全マスク解除 |

出力レベルを操作するスイッチ:

| オプション | 効果 |
|-----------|------|
| `-F<n>` | フェードイン/アウトします。`-85≦n≦-1`でフェードイン、`1≦n≦85`でフェードアウト（絶対値が大きいほど速い）、`n=0`で中断、省略時は既定速度でフェードアウトする |
| `-O<lv>[,n1,n2,...]` | 指定チャンネルの出力割合を設定します。`lv`は0〜128（128が基本＝最大音量、実際の音量は音源依存）。チャンネルを省略すると全チャンネルに適用。全パラメータを省略すると全チャンネルを基本状態(128)へ戻します。リアルタイムで変更可能 |

初期化・計算用のスイッチ:

| オプション | 効果 |
|-----------|------|
| `-I` | ZMUSICの演奏ワーク・FM音源・MIDI楽器等を初期化する（演奏中なら停止してから実行される） |
| `-Q[<演奏データ>]` | 演奏中またはトラックバッファ内のデータのトータルステップタイムを計算・表示する（`トラック番号: ループ外総カウント ループ内総カウント`、16進数）。`[do]`〜`[loop]`以外の書き方で無限ループを作ると計算が終わらない点に注意 |

MIDIダンプデータ（MDD）を扱うスイッチ:

| オプション | 効果 |
|-----------|------|
| `-A` | MIDI楽器からのデータ受信待機状態にする |
| `-A<ファイル名>` | 受信データをMDDとしてファイルへ保存する（拡張子省略時`.MDD`が自動で付く） |
| `-X<ファイル名>` | MDDファイルを楽器へ転送する（拡張子省略時`.MDD`が自動で付く） |

ジュークボックス機能:

| オプション | 効果 |
|-----------|------|
| `-J<インデックスファイル>[,<setup1>,...,<setup4>]` | インデックスファイル（拡張子省略時`.JUK`）に記載された演奏データ（最大64曲、ZMDのみ）を連続再生します。常駐する |

インデックスファイルの書式は`<繰り返し回数(1〜255,省略時1)>,<演奏データファイル名>`
（1行1曲、拡張子省略時`.ZMD`）。最後の曲を再生したら先頭に戻ってループします。ジュークボックス
実行中は事前に全データを読み込むためメモリを多く消費する一方、ZMUSIC.X側のバッファは
一切使わない（`-t0 -p0 -w0`で常駐していても動作する）。デバッグツール機能とは併用できず、
使うには`-R`でいったん終了する必要があります。

ジュークボックス実行中のキー操作（既定値、環境変数`zp_jukectrl`で変更可能）:

| キー | 動作 |
|------|------|
| SHIFT+OPT.1 | 次の曲へ |
| SHIFT+OPT.2 | フェードアウトして次の曲へ |
| SHIFT+CTRL | 一時停止／再開 |
| SHIFT+XF4 | 再演奏 |
| SHIFT+XF5 | フェードアウトして再演奏 |
| CTRL+OPT.1 | 前の曲へ |
| CTRL+OPT.2 | フェードアウトして前の曲へ |

制約: 無限ループは`[do]`〜`[loop]`のみ有効。ZPD指定（`.adpcm_block_data`）以外のADPCM
データ登録命令（`.adpcm_list`/`.Onk`等）を含む曲データは扱えません。

デバッグ・ツール機能:

| オプション | 効果 |
|-----------|------|
| `-D` | ZP.Rを常駐させ、キーボードによるリアルタイム演奏制御を有効にする |

デバッグツール常駐中のキー操作（既定値、環境変数`zp_keyctrl`で変更可能）:

| キー | 動作 |
|------|------|
| SHIFT+OPT.1 | 一時停止 |
| SHIFT+OPT.2 | 一時停止解除 |
| SHIFT+XF5 | 早送り（押している間だけ有効） |
| SHIFT+XF4 | REPLAY |
| SHIFT+XF3 | 低速演奏（押している間だけ有効） |
| SHIFT+XF1 | フェードアウト |
| SHIFT+XF2 | フェードイン |

こちらもジュークボックス機能とは併用できず、`-R`でいったん終了する必要があります。

常駐解除・同期演奏用のスイッチ:

| オプション | 効果 |
|-----------|------|
| `-R` | `-J`/`-D`で常駐したZP.Rを解除します。常駐していない状態で指定するとエラーになる |
| `-W <演奏データ>[,<setup1>,...,<setup4>]` | `-P`と同様に演奏を準備するが、セットアップ実行後はすぐ演奏を始めずMIDI同期スタートメッセージ($FA)の受信を待つ（複数X68kでの同期演奏用。ZMUSIC側は`-E`で常駐させておく必要がある） |

## ix68kでの利用

### 入手先・インストール

[ZMUSIC.X](ZMUSIC.X.md)と同じ配布アーカイブ`ZMSC208X.LZH`に同梱。入手先・インストール手順・
2.08eパッチ適用手順は[ZMUSIC.X.md](ZMUSIC.X.md)を参照（`\BIN\ZP.R`として同時にインストール・
パッチ適用済み）。

マニュアル出典: `ZMSC2MAN.LZH`同梱`ZM7.MAN`（MEASURE7「プレイヤーZP.R」、
`extern/zmusic/ZMSC2MAN/ZM7.MAN`に展開済み）。
