# HAPIC.X

> PICファイル（16・256・32K・64K色、正方形モード、DoGa形式）のローダー
> （表示専用、セーブ不可）。オリジナルのPIC.r v1.05比で平均1.5倍速、68030でも
> キャッシュ制御により正常動作。CONFIG.SYSの`DEVICE=`行からの常駐実行にも対応。

---

## リファレンス（一次資料要約）

### 起動・コマンドラインオプション

書式:

```
HAPIC <ファイル名> [オプション]
```

オプションの先頭には`/`と`-`のどちらも使えます。

| オプション | 効果 |
|-----------|------|
| `/c[n]` | 表示前の画面クリア方法を指定。何も付けなければn=1相当、`/c`単体（数値省略）ならn=3。n=0はクリアなし、1はテキストのみ、2はグラフィックのみ、3は両方クリア。さらに+4すると展開中のグラフィックを非表示にする |
| `/K` | 次の絵を表示する前にキー入力を待つ（待機中にESCで中断できる） |
| `/l[x,y]` | 表示位置の座標を指定する |
| `/m` | PICヘッダに埋め込まれたメッセージを表示しない |
| `/n` | 画面モードの切り替えをしない |
| `/r` | 指定パス配下のサブディレクトリも検索対象にする |
| `/s` | 未知の機種フラグを持つPICファイルをエラーとして扱う |
| `/t[n]` | 表示後、次の絵に移るまでn/100秒待つ（キー入力があれば待たずに進む） |
| `/u` | グラフィック・テキストVRAMの使用状況チェックを省略する |
| `/p` | パス区切り文字を`¥`から`/`へ変更する（変更後は`/`をオプション指定に使えなくなる） |
| `/x` | テキストVRAMを画像展開の作業バッファとして使わない |

ワイルドカードで複数ファイルを連続表示している最中は、ESCキーで中断できます。

終了コードの意味:

| コード | 意味 |
|-------|------|
| 0 | 正常終了 |
| 1 | メモリ不足 |
| 2 | ファイル形式が対象外 |
| 3 | 画像サイズが表示可能範囲外 |
| 4 | オプション指定の誤り |
| 5 | VRAMが使用できない状態 |
| 6 | ファイル名が不正（ドライブ指定の誤り等） |
| 7 | ファイルのオープンに失敗 |
| 8 | ESCキー押下による中断 |

## ix68kでの利用

### 入手先

配布元URL不明（手元のアーカイブコレクション由来）。
`arc/x68tools/VISUAL/LOADER/PIC/HAPIC130.LZH`に保存。

### インストール（SYSTEM_HD.HDSへの導入手順）

```sh
unar -o ./hapic_extracted arc/x68tools/VISUAL/LOADER/PIC/HAPIC130.LZH -e SHIFT_JIS
tools-host/hu68disk/hu68disk copy disk/SYSTEM_HD.HDS ./hapic_extracted/HAPIC130/HAPIC.X /BIN
tools-host/hu68disk/hu68disk copy disk/SYSTEM_HD.HDS ./hapic_extracted/HAPIC130/HAPIC.DOC /BIN
tools-host/hu68disk/hu68disk copy disk/SYSTEM_HD.HDS ./hapic_extracted/HAPIC130/HAPIC.HIS /BIN
```
