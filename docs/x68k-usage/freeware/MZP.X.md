# MZP.X

> Z-MUSIC上で他ドライバ（MXDRV, NAGDRV, RC(RCM/MCP/R36), MLD, 標準MIDIファイル）の
> 演奏データをデータ変換なしにそのまま演奏する「マルチミュージックプレーヤー」。
> 実際の変換は同梱の `MXtoZ.x` `NDtoZ.x` `RCtoZ.x` `MLtoZ.x` `SDtoZ.x` が拡張子に応じて
> 下請けとして行います。Z-MUSIC v2.00以上が常駐している必要があります。

---

## リファレンス（一次資料要約）

### 同梱ツール（rel.4時点）

| ファイル | 版 | 機能 |
|---------|----|----|
| MZP.x | v1.14c | マルチプレーヤー本体 |
| MXtoZ.x | v0.44b | MXDRVデータを変換して演奏 |
| NDtoZ.x | v0.47a | NAGDRVデータを変換して演奏 |
| RCtoZ.x | v0.47a | RCM(RCP/R36/MCP)データを変換して演奏 |
| MLtoZ.x | v0.23c | MLDデータを変換して演奏 |
| SDtoZ.x | v0.10 | 標準MIDIファイル(SMF)を変換して演奏 |

インストール済みrel.4bテスト版バイナリの内部バージョン番号は未確認（上表はrel.4時点の
参考値）。

MDF/ZDF形式（圧縮アーカイブ形式の演奏データ）を扱うには`lzz.r`（LZZ、RCシステムのLZMを
リロケータブル化・機能拡張したもの）がパスの通ったディレクトリに必要です。
**インストール済み**（[LZZ.R](LZZ.R.md)、v0.57aを`\BIN`へ導入）。

### 起動・コマンドラインオプション

書式:

```
MZP <スイッチ> [ファイル名][,セットアップファイル名…]
```

演奏開始・停止・状態表示など、演奏の進行そのものを制御するスイッチ:

| スイッチ | 効果 |
|---------|------|
| `-P[トラック番号,…]` | 演奏を開始する |
| `-S[トラック番号,…]` | 演奏を停止する |
| `-C[トラック番号,…]` | 演奏を再開する |
| `-D` | Z-MUSICの現在の状態を表示する |
| `-F[フェードアウトスピード]` | フェードアウトする（マイナス値を渡すとフェードイン） |
| `-E[チャンネル番号,…]` | 指定チャンネルだけをソロ演奏する |
| `-M[チャンネル番号,…]` | 指定チャンネルをミュートする |
| `-J[番号]` | 汎用ワークが指定値になるまで高速演奏する（省略時は0以外になるまで）。ESCで中断できる |
| `-K` | MDF演奏中にWRDファイル（歌詞等）を画面表示しながら演奏します。ESCで中断できる |

初期化・環境設定に関わるスイッチ:

| スイッチ | 効果 |
|---------|------|
| `-I` | Z-MUSICと接続中の全音源を初期化する |
| `-G` | オートGSモードにする（環境変数で既に有効なら逆にキャンセルする） |
| `-N` | CM64/GSへの全パラメータリセットを省略する（オートGS・エミュレートモードも合わせて無効化） |
| `-Q` | 画面表示を完全に抑制します。指定するなら最初に置く必要がある（rel.2h以降はRC関連ツールの表示も併せて抑える） |

データ変換・入出力系のスイッチ:

| スイッチ | 効果 |
|---------|------|
| `-A<ファイル名>` | MIDIデータの取り込み。ファイル名を省略すると取り込みを開始し、指定すると取り込んだデータをファイルへ書き出す |
| `-X<ファイル名>` | MIDIダンプデータを転送する |
| `-O` | オブジェクトファイルを作成する（`??toZ.x`系ツールと組み合わせ、MZPで再生できる形式=ZMSへ変換する） |
| `-V[ファイル名]` | ステップ数を表示する（`ZP.R`の`-Q`と同等の機能） |

セットアップファイルはコンマまたはスペース区切りで複数指定でき、2つ目以降は無条件で
`-N`扱いになります。演奏データ・セットアップファイルの拡張子は省略でき、その場合
`(ZMD-ZMS-OPM-ZPD-MDD)-MDX-MDN-MDF-(RCP-R36-MCP)-MDZ-MDI-(MID-MFF-STD)`の順で検索されます。

演奏データの検索先は拡張子ごとに異なる環境変数で指定する:

| 拡張子 | 環境変数 |
|--------|---------|
| ZMD, ZMS, OPM, ZPD, MDD | `zmusic`（`ZMUSIC`があれば優先） |
| MDN | `mdn` |
| MDX | `mxp` |
| RCP, R36, MCP, MDF | `rcp` |
| MDZ | `mlp` |
| MDI | `mdp` |
| MID, MFF, STD | `rcp` |

環境変数`mzp_opt`には、大文字小文字を区別する1文字ずつの機能フラグを順不同で連結して
指定する（例: `set mzp_opt=GLw3z`）:

| 文字 | 効果 |
|------|------|
| `A` | CM6ファイルを全転送する（通常は不要） |
| `C` | 演奏データ検索時にメディアの入れ替わりをチェックする |
| `E` | MT32/CM32L+SC55上でCM64の音色をエミュレートする |
| `G` | オートGSモードにする |
| `g` | 強制的にGSモードにする |
| `J` | ZMDデータを解析・書き換えて演奏する（V1.2以前のZMD互換。エミュレートモード使用時は必須） |
| `L` | RCMデータの255/256回ループを無限ループへ置き換える |
| `Q` | 演奏中の画面表示を完全に抑制する |
| `S` | `??toZ.x`系ツールを環境変数`path`に従って検索する |
| `T` | タイマー値のテンポを音楽的なテンポ表記へ変換する（ZMS/ZMDには適用されない） |
| `a` | Z-MUSIC未常駐時に`mzp_player`で指定した別のプレイヤを代わりに起動する |
| `d` | トータルステップ表示を拡張形式（10進、総数/192の商と余り）にする |
| `h` | RCMデータのホールド1を`@D`表記へ変換する（見やすくなる代わり演奏の正確さは落ちる） |
| `r` | RCM/SMFのベンドをできるだけ相対ベンドコードで生成する（トラックバッファの節約になる） |
| `s` | オプション指定に`/`を使えなくする |
| `v` | 音色設定でZMD専用コマンドを使う（ハードLFOを使うデータ等で内蔵音源の再現性が上がる） |
| `w<n>` | CM6/GSDファイル転送時の待ち時間（0〜254、既定0） |
| `z` | MDF/ZDF展開時に`lzz.r`を優先して探す（見つからなければ`lzm.r`。指定なしはこの逆順） |

環境変数`mzp_player`はZ-MUSIC未常駐時の代替プレイヤをコンマ区切りで指定するもので
（順序はMXDRV,NAGDRV,RCD(MDF),RCD(MCP/RCP),MLD,MDDに対応）、既定値は
`mxp,np,lzz,rcp,mlp,mdp`。

### 終了コード

| コード | 意味 |
|-------|------|
| 1 | コマンドラインの指定が正しくない |
| 2 | メモリ不足 |
| 3 | 指定されたファイルが見つからない |
| 4 | 対応する`??toZ.x`が見つからない |
| 5 | データの種類が違う |
| 6 | Z-MUSIC側のエラーで演奏できなかった |
| 7 | Z-MUSICが常駐していない、またはバージョンが古い |
| 8 | PCMバッファが不足している |
| 9 | 変換中に想定外のコードを検出した（内部バグの可能性） |
| 10 | 書き込みできない |
| 11 | ファイルを作成できない |
| 12 | 内部バッファが不足している |
| 13 | lzm(lzz)が見つからない |
| 14 | lzm(lzz)またはRCコンバータでエラーが発生した |
| 15 | RCコンバータが見つからない |
| 16 | MIDIデータの文字型変換に失敗した（主にZ-MUSICのワーク不足） |
| 17 | トラックバッファが不足している |
| 18 | lzzでの展開に失敗した |
| 19 | Human68kのバージョンが古い |

### 既知の制限

- NAGDRV: LFO変換が不完全、強制キーオン非対応、疑似リバーブ・ファジーテンポ非対応
- MXDRV: 相対音量変化の再現が完全でない
- RCM: 和音関連が不完全、RCM v2.5はほぼ非対応、マイナーコマンド非対応
- MLD: MLD独自機能の多くが再現されない
- SMF: 極端に細かい分解能は変換できない、テンポ300超は300に丸められる、フォーマット2は非対応

### 入手先

同ディレクトリに複数版を保存:
- `arc/x68tools/SOUND/ZMUSIC/MZP/MZP04.LZH` — rel.4（test2）。マニュアル一式

  を同梱。**本マニュアルの出典**。
- `arc/x68tools/SOUND/ZMUSIC/MZP/MZP04B_T.LZH` — rel.4bテスト版。**インストール済み**。
  同梱READMEに「rel.4aからあまり変わってない」とあり機能はrel.4とほぼ同一と推定されるが、
  厳密な差分は`MZP4_HIS.DOC`記載のrel.4 test1/test2止まりで、4a→4bの変更点は未文書化。
- 配布元URL不明（リポジトリ内アーカイブコレクション由来）。旧版`MZP03*`〜`MZP113`等も
  同ディレクトリに保存済み。

### インストール（SYSTEM_HD.HDSへの導入手順）

```sh
unar -o ./mzp_extracted arc/x68tools/SOUND/ZMUSIC/MZP/MZP04B_T.LZH -e SHIFT-JIS
# → ./mzp_extracted/MZP04B_T/{MZP.x, MXtoZ.x, NDtoZ.x, RCtoZ.x, MLtoZ.x, SDtoZ.x, README}

for f in MZP.x MXtoZ.x NDtoZ.x RCtoZ.x MLtoZ.x SDtoZ.x; do
  tools-host/hu68disk/hu68disk copy disk/SYSTEM_HD.HDS "./mzp_extracted/MZP04B_T/$f" /BIN
done
```

2026-08-08、上記手順で `/BIN` への導入を実施済み（6ファイルとも展開時のオリジナル
タイムスタンプ保持のままコピー成功）。
