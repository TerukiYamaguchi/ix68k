# ZX.R (zx)

> ZIPアーカイブ高速展開プログラム。拡張子`.zip`のファイルを展開、自己展開形式にも対応。Human68k ver.2.02以降で動作。`lx.r`（LZH版、[freeware/LX.R.md](LX.R.md)）の姉妹ツールで同一作者・同一オプション体系（`-f`オプションのみ無し）。

---

## リファレンス（一次資料要約）

### 起動・コマンドラインオプション

書式:

```
zx [-[xetc[012]]lv1amnip[sw]] [-b path] zipfile [extfile [...]]
```

`zipfile`は展開するアーカイブ名（拡張子省略時は`.zip`を付加、ワイルドカード可）。`extfile`は
展開したいファイル名（省略時は全ファイル、ワイルドカード可）。環境変数`zx_opt`の中身が
コマンドラインの先頭に挿入されます。

展開の基本動作を決めるオプション:

| オプション | 効果 | 検証 |
|-----------|------|------|
| `-x[012]` | 展開する（ディレクトリ構造を再現する）。指定なしのときの既定動作。数値でCRCテストのレベルを指定できる | 📖 |
| `-e[012]` | 展開する（ディレクトリ構造は再現しない） | 📖 |
| `-t[012]` | 展開はせずCRCテストだけ行う（`0`=全ファイル対象／`1`=無圧縮部のみ／`2`=なし、既定`0`） | 📖 |
| `-b path` | 展開先ディレクトリを指定する（アーカイブ側が絶対パスを指定していても強制的にここへ展開する） | ✅ `-mb`で使用、正しく指定先へ展開 |
| `-p` | 展開結果を標準出力へ流す（`-n`を同時指定した扱いになる） | 📖 |
| `-s` | 展開先の空き容量を確認する（`-w`とは排他） | 📖 |
| `-w` | 複数ファイル展開時、いったんメモリ上にまとめてから一括でディスクへ書き出す（`-s`とは排他） | 📖 |

表示・確認まわりのオプション:

| オプション | 効果 | 検証 |
|-----------|------|------|
| `-l`, `-v` | アーカイブ内のファイル一覧を表示する | 📖 |
| `-1` | ファイル名だけを一覧表示する | ✅ `ZX -1 test.zip`で正しく表示 |
| `-a` | 属性情報を復元します。zipコメントがあれば表示する | 📖 |
| `-c[012]` | 同名ファイルが既にある場合の動作（`0`=常に上書き／`1`=展開側が新しい時だけ確認／`2`=常に確認、既定`0`） | 📖 |
| `-m` | 同名ファイルは確認なしでスキップする | ✅ `-mb`で使用、無人展開を確認 |
| `-n[012]` | 画面表示の制御（既定は標準エラー出力） | 📖 |
| `-i` | 展開ファイル名の指定で大文字小文字を区別する | 📖 |

`lx.r`にある`-f`（不当なアーカイブの強制展開）はzx.rには無い。終了コード: ヘルプ表示時・
エラー時は非0を返す（ファイル書き出し自体の失敗はエラー扱いにならない点に注意、と
原資料に明記されている）。

## ix68kでの利用

### 入手先

http://retropc.net/x68000/software/tools/archiver/zx/ から`ZXR120FS.LZH`としてダウンロード可能（v1.20 正式公開版、ソースあり）。
**`arc/ZXR120FS.LZH`にローカル保存済み**（2026-07-30取得）。再検証・再インストール時は
retropc.netへ再度アクセスせず、まずこちらを使うこと。

### インストール（SYSTEM_HD.HDSへの導入手順）

CONFIG.SYS登録不要。PATHの通ったディレクトリ（`\BIN`等）に`zx.r`本体を置くだけで`zx`コマンドとして使えます。

```sh
# 1. ダウンロード（arc/ZXR120FS.LZHにローカル保存済みならそれを使い、再ダウンロードしない）
cp arc/ZXR120FS.LZH ./ZXR120FS.LZH
# 無ければ: curl -LO http://retropc.net/x68000/software/tools/archiver/zx/ZXR120FS.LZH

# 2. 展開（unar、要 brew install unar。LZH形式）
unar -o ./zx_extracted ZXR120FS.LZH
# → ./zx_extracted/ZXR120FS/{ChangeLog.120, zx.hed, zx.1, zx.r, zx.has}

# 3. 本体(zx.r)のみをHDSの\BINへコピー（hu68disk、エミュレータ停止中に実行）
tools-host/hu68disk/hu68disk copy disk/SYSTEM_HD.HDS ./zx_extracted/ZXR120FS/zx.r /BIN
```

`zx.1`（マニュアル）・`zx.has`（ソース）・`ChangeLog.120`・`zx.hed`は実行に不要のためHDSへはコピーしません。

### MCP アクション

```
run_command("ZX -l ARCHIVE.zip")           # アーカイブ内一覧表示
run_command("ZX ARCHIVE.zip")              # カレントディレクトリへ展開
run_command("ZX -e ARCHIVE.zip")           # ディレクトリ構造を無視して展開
run_command("ZX -1 ARCHIVE.zip")           # ファイル名のみ一覧表示（✅検証済み）
run_command("ZX -mb DESTDIR ARCHIVE.zip")  # 確認なしでDESTDIRへ展開（✅検証済み）
```

`\BIN`がPATH外の場合はフルパス指定（`C:\BIN\ZX ...`）で呼び出します。

### 検証メモ

- 検証: 2026-07-30、SYSTEM_HD.HDS(`\BIN\ZX.R`)からix68k起動して確認。
  - `ZX -1 test.zip`: アーカイブ内ファイル名を正しく表示
  - `ZX -mb OUT test.zip`: 実展開に成功、展開先の実ファイルサイズがホスト側オリジナルと一致
- 出典アーカイブ: `ZXR120FS.LZH`（21.5KB、`ChangeLog.120`/`zx.hed`/`zx.1`/`zx.r`/`zx.has`を同梱）。
- **重要な制約**: `zx.r`(1995年製)は**macOS標準の`zip`が付与する拡張フィールド
  （`0x5455` universal time／`0x7875` Unix UID・GID）を含むzipを「ファイル構造が異常です」
  で拒否する**。テスト用zipを作る際は`zip -X`（拡張属性を除外）で作成すること。
  最初`zip`（オプションなし）で作った`test.zip`は失敗し、`zip -X`で作り直した`test2.zip`
  （拡張フィールド0バイト）で成功しました。実際の配布物（既存の`.zip`アーカイブ）がこの
  制約に該当するかは未確認——**古い`zx.r`と非互換なzipに遭遇する可能性がある**ため、
  実運用で展開エラーが出た場合はこの制約を疑うこと。
- 未検証: `-x`（ディレクトリ構造再現）・`-t`（CRCテスト）・`-c`（同名ファイル確認動作）・
  `-a`（zipコメント表示）等その他オプション。
