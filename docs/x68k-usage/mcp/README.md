# MCPによるX68000操作

Codex、Claude Code、LM Studioなど、MCP対応のAIエージェントがix68kを操作するための資料。
人間が画面とキーボードで使う通常の操作は [guide/](../guide/README.md) を参照します。

1. [MCP設定](mcp_llm_setup.md) でエミュレータとクライアントを接続します。
2. [エージェント運用ガイド](agent_playbook.md) を読みます。
3. [日常的な操作フロー](daily_workflows.md) を使います。
4. 新規環境の構築は [環境構築レシピ](provisioning/README.md) の固定手順を使います。

ツールの引数・応答形式は `tools-host/mcp/MCP_TOOLS.md` を正本とします。
