# MCP対応のAIエージェントの運用ガイド

Codex、Claude Code、LM Studioなど、MCPを使えるエージェントに共通する運用規約。クライアント固有の
接続設定は [MCP設定](mcp_llm_setup.md)、ツール引数は `tools-host/mcp/MCP_TOOLS.md` を正本とします。

1. 操作前にエミュレータ接続、現在の媒体、プロンプトまたは停止状態を確認します。
2. ユーザーの目的を、起動・確認・ファイル転送・設定変更・デバッグの小さな操作へ分けます。
3. 通常のコマンドは `run_command`、入力待ちは `key_wait`、特殊キーは `key` を使います。
4. 変更する前に対象パスとドライブを確認します。ホスト側とゲスト側のパスを混同しません。
5. ディスク排出、ライトプロテクト変更、ファイル上書き、`CONFIG.SYS`／`AUTOEXEC.BAT`変更は影響を説明し、
   必要ならバックアップを取る。
6. 操作結果は画面、終了コード、`disk(status)`、または対象ファイルの再読出しで確認します。
7. 非停止のテキスト観測には `read_text_events` を使います。通常は戻り値の `streams[*].text` だけを読み、必要なときだけ `detail="events"` と最小限の `fields` を指定します。連続観測では前回の `next_seq` を `since_seq` に渡します。

エージェントは、未確認のX68000コマンドやキー操作を推測しません。親READMEの逆引きと個別文書を優先し、
文書が無い操作は安全な確認をしてからユーザーへ状況を報告します。
