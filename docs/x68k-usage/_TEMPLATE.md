## ix68kでの利用

インストール手順・MCP操作・ix68k検証結果など、一次資料には無い本プロジェクト固有の内容。

### 入手先

配布元URL。official（Human68k付属）はこのセクションごと削除する。

### インストール（HDSへの導入手順）

ダウンロード→展開→HDSへコピー、を再現可能なコマンド列で記載する（ホスト側で完結、
エミュレータ停止中に実行）。CONFIG.SYS登録が必要なドライバ類はその設定例も書く。
既にHDSに存在確認済みの他ソフト（`freeware/SUSIE.X.md` `freeware/LX.R.md`等）を参考に。
不要なら（記憶で埋めず出典が無いなら）このセクションごと削除する。

**ダウンロードしたアーカイブは`arc/`に保存し、再検証・再インストール時は配布元へ
再アクセスせずそちらを使う**（配布元サーバへの負荷軽減）。

```sh
cp arc/<アーカイブ名> ./<アーカイブ名>    # 無ければ: curl -LO <配布元URLの直リンク>
<展開コマンド>   # 例: unar -o ./out archive.lzh （要 brew install unar、LZH形式）
tools-host/hu68disk/hu68disk copy <対象HDS> <展開後の実行ファイル> <配置先パス>

# 付属ドキュメント（マニュアル・ChangeLog等、ソース/サンプルは除く）はHDS内
# \DOC\<実行ファイル名(拡張子抜き)>\ へ配置し、ix68k上でも参照可能にする
tools-host/hu68disk/hu68disk mkdir <対象HDS> /DOC/<コマンド名>
tools-host/hu68disk/hu68disk copy <対象HDS> <展開後のdocファイル> /DOC/<コマンド名>
```

### MCP アクション

起動例:

```
run_command("<COMMAND>")
```

「起動後の操作」に対話操作がある場合は、同じ「操作」名で対応させる:

| 操作 | MCP アクション | 検証 |
|------|---------------|------|
| 終了（保存せず） | `key(action="press", key="ESCAPE")` → `paste_text("...")` | ❌ |
| 保存 | ... | ❌ |
