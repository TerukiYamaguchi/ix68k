# X68000 を使い始める

X68000 や Human68k が初めての人が、ix68kを画面とキーボードで使い始めるための入口。
個別ソフトの操作は親ディレクトリの [操作リファレンス](../README.md) を参照します。

読む順序:

1. [環境を確認する](environment.md)
2. [Human68kの基本](human68k_basics.md)
3. [ホストとゲストの間でファイルを渡す](file_transfer.md)
4. 作業ディレクトリを共有するなら [HOSTDRV ユーザーズマニュアル](hostdrv.md)
5. ジョイパッドを使うなら [ジョイパッドを使う](joypad.md)
6. 困ったときは [トラブルシュート](troubleshooting.md)

MCP対応のAIエージェントによる操作は [mcp/](../mcp/README.md) を参照します。
