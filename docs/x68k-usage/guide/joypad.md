# ジョイパッドを使う

USBのジョイパッドを、X68000のジョイスティックとして使う手順。パッドが反応しないとき、
2台使うとき、使いたいパッドが#2になっているときに読みます。

## ボタンの対応

| ホストのパッド | X68000 |
| --- | --- |
| 十字キー | 上下左右 |
| A（下側のボタン） | トリガ A |
| B（右側のボタン） | トリガ B |
| BACK | SELECT（上下の同時押し） |
| START | START（左右の同時押し） |

X68000のジョイスティックポートは、4方向と2ボタンしか持ちません。SELECT / START は、
上下 / 左右の同時押しとして表す慣例に従っています。方向レバーを倒しただけで SELECT / START が
押されたことになる不良パッドでは、`ix68k.cfg` の `joystick_select_start = false` で
この合成を止められます。

## ジョイスティック#1と#2

X68000には本体背面にジョイスティックポートが2つあります。ゲームは次のように読みます。

- 1人用のゲームは、ほとんどが#1だけを読みます。
- 2人同時プレイのゲームは、#1と#2の両方を読みます。

ix68kは、起動時に見つかったパッドへ、見つかった順に `Gamepad#1`、`Gamepad#2`、…（最大8台）と
番号を付けます。既定では、`Gamepad#1` が#1、`Gamepad#2` が#2になります。起動ログに次のように出ます。

```
Gamepad#1 connected: <パッド名>
Gamepad#2 connected: <パッド名>
```

## 割り当てを確認する

同梱の `JOYGET_TEST.X` を使います（リリースZIPでは `tools-x68k/joyget_test/JOYGET_TEST.X`、clone した場合は `tools-x68k/joyget_test/joyget_test.x`）。IOCS `_JOYGET` の値を画面に表示するツールで、
ゲームが読む値と同じものを確認できます。

1. `JOYGET_TEST.X`（clone した場合は `joyget_test.x`）をゲストへ渡します。ホストの共有フォルダ（`ix68k.cfg` の `hostdrv_dir`）に
   置くと、HOSTDRVのドライブから実行できます。手順は
   [ホストとゲストの間でファイルを渡す](file_transfer.md) を参照します。
2. Human68kのプロンプトで `JOYGET_TEST` を実行します。画面に `JOY#1:` と `JOY#2:` の2行が出ます。
3. パッドを1つずつ押す（B ボタンか十字キー）。どちらの行にボタン名が出るかを見ます。
4. ESC で終了します。

使いたいパッドが `JOY#1:` に出ていれば、設定は不要です。

## 割り当てを変える

使いたいパッドが `JOY#2:` に出る、または繋いだ順と番号が合わない場合は、`ix68k.cfg` の
`joy1` / `joy2` に、起動ログの `Gamepad#N` の番号 N（1〜8）を指定して再起動します。
`joy1` が#1、`joy2` が#2に使うパッドです。

```
joy1 = 2
joy2 = 1
```

この例は、`Gamepad#2` を#1に、`Gamepad#1` を#2にする（2台のパッドの入れ替え）。
`0` または未指定なら、#1は `Gamepad#1`、#2は `Gamepad#2` を使います。
設定を変えたら、`JOYGET_TEST.X` でもう一度確認します。

## 注意

- ホストが返すパッドの順番は、繋いだ順と一致しないことがあります。実測では、macOSで同じ機種の
  パッド2台を繋いだとき、先に繋いだほうが `Gamepad#2` になりました。
- 同じ機種のパッドを2台繋ぐと、起動ログの名前だけではどちらがどちらか分かりません。
  `JOYGET_TEST.X` で1台ずつ押して確認します。
- パッドを繋ぎ直したり、ix68kを再起動したりすると、番号が入れ替わることがあります。
  その場合は `joy1` / `joy2` を書き換えます。
- パッドはix68kの起動前に繋ぐと、起動ログで番号を確認しやすい。起動後に繋いだパッドも、
  空いている番号のうち最小のものに割り当てられます。
