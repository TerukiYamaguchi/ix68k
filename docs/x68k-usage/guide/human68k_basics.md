# Human68k の基本

Human68kはDOS系のコマンド環境です。プロンプトの `A>` や `C>` は現在ドライブを表します。

- パスは `C:\BIN\TOOL.X` のようにバックスラッシュで区切る。
- `DIR` で一覧、`CD DIRNAME` で移動、`TYPE FILE.TXT` で表示します。
- `A:` のように入力するとドライブを切り替えます。
- コマンド名は通常 `.X` を省略して実行できます。例: `ED FILE.TXT`。
- ゲスト内のファイル名は、古いソフトとの互換性のため8.3形式を優先します。

まず `VER`、`DIR`、`DIR \BIN` を実行して、起動済みの環境を壊さずに把握します。
個別のコマンドは [official/](../official/) と [freeware/](../freeware/) の文書を逆引きします。

## テキストファイル

Human68kで扱うテキストファイルは、基本的にShift-JIS（実用上はCP932）、CRLF改行
（`0D 0A`）で保存し、ファイル末尾にEOFマーカーの`$1A`（Ctrl-Z）を置きます。バッチファイル、
設定ファイル、文書を含め、当時のツールとの互換性を保つための基本形式です。

`.TXT`だけでなく、`.DOC`も多くの場合はプレーンテキストの文書です。X68000上の`.DOC`は
Microsoft Wordの文書形式を意味しません。拡張子だけで断定はできないが、配布物に含まれる
`README.DOC`やマニュアル類は、まずテキストビューアやエディタで開きます。

macOSやLinuxのエディタはUTF-8・LF改行を標準にすることが多いため、X68000へ渡す前に
文字コードと改行を確認します。新規作成・変換時は、Shift-JISまたはCP932、CRLF、末尾の
`$1A`（1バイトの`0x1A`）を使います。既存ファイルを編集する場合は、文字コード・CRLF・末尾の
`$1A`を保持します。GhostED（`GED.X`）では末尾の`$1A`を検出し、追記をその直前に入れるため、
通常は位置を意識せず編集できます。

すべてのファイルがこの形式とは限りません。バイナリファイルや、現代のツールが生成したUTF-8の
テキストは、内容と利用するソフトウェアを確認してから変換します。

## 終了と中断

Human68kには終了コマンドはありません。ディスクキャッシュを導入しておらず、フロッピーまたは
ハードディスクへのアクセス中でなければ、基本的にはいつでもix68kを終了できます。ただし、
アプリケーションで未保存の変更があれば失われます。ディスクキャッシュを使う場合は、キャッシュを
フラッシュしてから終了するか、そのソフトウェアの手順に従います。

実行中のプログラムから抜けられないときは、ix68kの`Interrupt`（ホストの`Pause`キー）を
押します。Human68kのBREAKキー相当のNMIを発生させ、通常は実行を中断してCOMMAND.Xの
コマンドラインへ戻る。ディスクアクセス中や書き込み中に中断・終了してはなりません。

## AIエージェントに操作を任せるとき

AIエージェントに継続して操作させるときは、COMMAND.Xのプロンプト（`A>`や`C>`）で
次のコマンドを待つ状態に戻しておきます。コマンド実行中やアプリケーションの入力待ちのままにせず、
作業の区切りごとにプロンプトへ復帰させると、次の指示を確実に渡せます。プログラムが応答しない
場合は、エージェントから`send_interrupt`を使うか、`Interrupt`（`Pause`キー）で中断します。
MCPを使う具体的な手順は [MCPガイド](../mcp/README.md) を参照します。
