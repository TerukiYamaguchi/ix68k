# HOSTDRV ユーザーズマニュアル

HOSTDRV は、ホスト側の一つのディレクトリを Human68k のドライブとして共有する機能です。
ホストで編集したファイルを、ディスクイメージを更新・再起動せずにゲストから使いたいときに使います。

## 1. できることと前提

HOSTDRV を有効にすると、指定したホスト側ディレクトリが Human68k のリモートドライブになります。
`DIR`、`COPY`、`CD`、プログラムの実行など、通常のドライブと同じように操作できます。ファイルの
作成・変更・削除はホスト側の共有ディレクトリへ反映されます。

次の三つが必要です。

1. ix68k の設定ファイルに `hostdrv_dir` を設定します。
2. 起動する Human68k のシステムディスクに `HOSTDRV.SYS` を置きます。
3. `CONFIG.SYS` に `DEVICE = \SYS\HOSTDRV.SYS` を登録します。

初回の HDD 作成と導入をまとめて行う場合は、[SCSI HDD インストール](../mcp/provisioning/hdd_install.md)
の HOSTDRV の手順も参照します。

## 2. ホスト側の設定

共有したいディレクトリを作り、ix68k の設定ファイルに絶対パスを指定します。例えば macOS では
次のようにします。

```ini
hostdrv_dir = /Users/your-name/x68k-work
```

設定例は [profiles/ix68k.cfg.example](https://github.com/TerukiYamaguchi/ix68k/blob/main/profiles/ix68k.cfg.example) にもあります。設定を変更したら
ix68k を終了してから再起動します。空の値、または存在しないパスでは HOSTDRV は利用できません。

## 3. ゲスト側への導入

ビルド済みの `HOSTDRV.SYS` を、起動ディスクの `\SYS` へコピーします。

```sh
tools-host/hu68disk/hu68disk copy disk/SYSTEM_HD.HDS \
  tools-x68k/hostdrv/HOSTDRV.SYS /SYS
```

次に、ディスク内の `CONFIG.SYS` に次の一行を追加します。

```text
DEVICE = \SYS\HOSTDRV.SYS
```

`CONFIG.SYS` を変更した場合は Human68k を再起動します。ディスクイメージの更新は、ix68k を停止して
から行います。稼働中の固定 HDD イメージをホスト側から直接書き換えないこと。

## 4. 割当ドライブの確認

起動時、HOSTDRV は実際に割り当てられたドライブ文字を表示します。

```text
HOSTDRV Ver.1.0: A: をホスト共有ドライブに割り当てました。
```

この例では `A:` が共有ドライブです。割当先は、ほかのデバイスドライバと `CONFIG.SYS` の登録順に
よって変わるため、表示された文字を使うこと。ドキュメント中の `A:` は例であり、常に `A:` とは限りません。

表示を見逃した場合は、Human68k を再起動して確認します。

## 5. 基本操作

共有ドライブが `A:` に割り当てられた場合の例です。

```text
A:
DIR
MD \WORK\DEMO
CD \WORK\DEMO
COPY C:\TOOLS\HELLO.X A:\WORK\DEMO
HELLO
```

ホスト側では `/Users/your-name/x68k-work/WORK/DEMO` に同じファイルが現れます。ネイティブ開発では、
ホスト側で編集したソースを共有ドライブに置き、Human68k 上でコンパイル・実行する流れに向きます。
具体例は [ネイティブビルド](../development/native_build.md) を参照します。

## 6. 注意点

- `CD ..` のような相対親ディレクトリへの移動は Human68k 側の制約で失敗します。`CD A:\` や
  `CD A:\WORK` のように絶対パスを使います。
- `CONFIG.SYS` のほかのドライバでドライブ文字を明示指定すると、ドライブ文字に空きができる場合があります。
  Human68k 3.02 では、その後に登録するデバイスドライバでアドレスエラーになります。明示指定する
  ドライバは `*:` または `@:` による自動割当を使います。詳細は
  [HOSTDRV と他のデバイスドライバの併用](file_transfer.md#hostdrvと他のデバイスドライバの併用) を参照します。
- ゲストのファイル名は Shift-JIS、ホスト側は UTF-8 として扱われます。変換できない文字を含む名前は
  避けます。
- HOSTDRV は共有ディレクトリの外側へアクセスできません。`..` などで共有ルートの外へ移動することはできません。
- 共有ディレクトリ内のシンボリックリンクはゲストから見えません（リンク先が共有ディレクトリの外を指しうるため）。
  共有したいファイルは、リンクではなく実体を置きます。共有ディレクトリそのものをリンクで指定するのは構いません。

## 7. 困ったとき

| 症状 | 確認すること |
| --- | --- |
| 起動時に HOSTDRV の表示がない | `CONFIG.SYS` の `DEVICE = \SYS\HOSTDRV.SYS`、`\SYS\HOSTDRV.SYS` の配置、再起動を確認します。 |
| ドライブが見つからない | 起動時表示のドライブ文字を確認します。想定した文字に固定しません。 |
| ファイルが見えない | `hostdrv_dir` の絶対パス、ホスト側ディレクトリの存在、現在のゲスト側ドライブを確認します。 |
| `CD ..` が失敗する | 共有ドライブの絶対パスを指定して移動します。 |
| 起動時にアドレスエラーになる | 明示的なドライブ文字指定による非連続な構成がないか確認します。 |
| `HOSTDRV: ホストディレクトリが未設定のため組み込みません。` と表示される | ix68k の設定ファイルの `hostdrv_dir` を確認します。ドライブは登録されず、起動は続行します。 |
| `HOSTDRV: ix68k 以外では組み込めません。` と表示される | ix68k 以外のエミュレータや実機で起動しています。HOSTDRV は ix68k 専用で、ドライブは登録されず、起動は続行します。 |

一般的な媒体・起動の問題は [トラブルシュート](troubleshooting.md) を参照します。内部の構成や対応する
ファイル要求は、開発者向けの [HOSTDRV リモートデバイス設計](https://github.com/TerukiYamaguchi/ix68k/blob/main/docs/ix68k-internals/design/hostdrv_design.md) に記載しています。
