# 起動エラーの見分け方（ROM・機種の指定ミス）

ix68k が起動しない、または画面が思いどおりに出ないときの原因を、症状から引くための表。
ROM・CGROM・`series`・CPU の指定ミスを、実際に試した結果でまとめています。

## 最初に確認すること

- 正常に起動したのに「ディスクから起動できません。正しいディスクをセットしてください。」と出る場合は、
  ROM は正しい。起動用のディスクを指定します。
- ix68k がダイアログを出して終了する場合は、ダイアログの指示に従う（次節）。
- ダイアログが出ずに、画面が黒い・文字が出ない・文字化けする場合は、「ix68k が検出しないケース」の節を見ます。

## ix68k がダイアログを出して終了するケース

| 設定 | ダイアログの要点 | 原因と対処 |
| --- | --- | --- |
| `rom` を指定していない | IPLROM が指定されていません | `-rom` または設定ファイルの `rom =` に IPLROM を指定する |
| 指定した ROM が存在しない・空・ディレクトリ | IPLROM を読み込めません | パスとファイルを確認する |
| 256KB 版（IPLROM16_256K.DAT）、SCSIINROM 単体（8KB）、CGROM（768KB） | IPLROM のサイズが不正です | IPLROM は 128KB または 1MB のものを指定します。CGROM は `cgrom` に指定する |
| ROM ではないファイル（128KB のランダムデータ） | IPLROM ではないファイルが指定されています | `rom` に別のファイルを指定していないか確認する |
| IPLROM30.DAT + `series = x68000`（または `xvi`） | この IPLROM は X68030 用で、68000 / 68010 では動きません | `series = x68030` を指定するか、X68000 用の IPLROM に変更する |
| IPLROM.DAT + `series = x68030` | IPLROM の機種と series が一致しません | ファイル名に対応する `series` を指定する |
| `cgrom` を指定していない（128KB の IPLROM を使う場合。ヘッドレス版は対象外） | CGROM が指定されていません | `-cgrom` または設定ファイルの `cgrom =` に CGROM（768KB）を指定します。1MB のフルイメージ ROM はフォントを含むため不要 |
| `cgrom` に存在しない・空・ディレクトリのファイルを指定 | CGROM を読み込めません | パスとファイルを確認する |
| `series = x68000` + `cpu_model = 68030` | series = x68000 には cpu_model = 68000、cpu_clock = 10 MHz が必要です | 機種を変えるなら `series` を指定する |
| `series = xvi` + `cpu_clock = 25` | series = xvi には cpu_model = 68000、cpu_clock = 16 MHz が必要です | 同上 |
| `series = x68000` + `accelerator = 060turbo` | accelerator は X68030 専用です | `series = x68030` を指定する |
| `series = x68030` + `accelerator = 060turbo` + `cpu_model = 68040` | series = 060turbo には cpu_model = 68060、cpu_clock = 50 MHz が必要です | 060turbo は 68060 / 50MHz、040turbo は 68040 / 25 または 33MHz |

### ROM ファイル名と series の対応

| ROM のファイル名 | 対応する series |
| --- | --- |
| IPLROM.DAT / IPLROMCO.DAT / IPLROMXV.DAT | x68000 または xvi |
| IPLROM30.DAT / IPLROM16.DAT | x68030（accelerator を含む） |

これ以外のファイル名（新しい版の ROM など）は、`series` との照合をしません。

## ix68k が検出しないケース

ROM として読み込めるものの、画面や動作がおかしくなる例。ix68k は何も表示せず起動します。
CGROM を指定していない場合や、読み込めない場合は、ダイアログが出る（前節）。

| 設定 | 画面の様子 | 原因と対処 |
| --- | --- | --- |
| `cgrom` に IPLROM を指定 | 文字の部分が模様のように崩れる | `cgrom` には CGROM を指定する |
| X68000 用の ROM を別の名前にコピーして `series = x68030` で使う | 正常に起動する（X68000 の画面） | ROM のファイル名を変えると、機種の取り違えを検出できない |

起動デバイスに SCSI を指定していても、IPLROM に SCSI 用の ROM が含まれていない場合は、
フロッピーなしの起動と同じ「ディスクから起動できません」が出ます。

## 正常起動の目安

ディスクを指定しない場合、次の表示になれば ROM と構成は正しい。

| 設定 | 画面 |
| --- | --- |
| IPLROM.DAT + `series = x68000` | 「ディスクから起動できません。正しいディスクをセットしてください。」 |
| IPLROMXV.DAT + `series = xvi` | 同上 |
| IPLROM30.DAT + `series = x68030` | 同上（起動の表示まで 20 秒ほどかかる） |
| IPLROM16.DAT + `series = x68030` + `accelerator = 060turbo` | ROM のバージョンや CPU の情報に続いて、同じメッセージ |

## 実測の条件

- ヘッドレス版（`ix68k-nogui`）で、設定ファイルを使わずにコマンドラインから起動して確認しました。
- 画面は TVRAM のスクリーンショットで確認しました。
- ROM は手元の実機 ROM を使い、機種違い・サイズ違い・ランダムデータは使い捨てのファイルで再現しました。
