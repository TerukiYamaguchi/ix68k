# ビデオコントローラ実装状況

ビデオコントローラの現行仕様は
[`video_controller_design.md`](../design/video_controller_design.md) を参照します。CRTC の走査
タイミング・表示領域・スクロールは [`crtc_support.md`](crtc_support.md) の対象です。

> **必須**: R1/R2、パレット、コントラストまたはレイヤ合成を実装・変更したら、本書を更新します。

## レジスタと機能

| 対象 | アドレス | 実装状況 |
| --- | --- | --- |
| R0（実画面サイズ／色モード） | `$E82400` | 🔄 ROM は書き込むが、ix68k は `$93C` を基に色モードを判定するため未使用 |
| R1（ページ間・GR/TX/SP優先順位） | `$E82500` | ✅ GP0–3によるページ合成順と、GR/TX/SP-BGの3レイヤ順を反映 |
| R2（表示制御・特殊表示） | `$E82600` | ✅ GS4–0、TON、SON、AH、G/G、G/T、B/P=0、特殊優先順位を反映。❌ YS/VHT（外部ビデオ入力）は未対応 |
| グラフィックパレット | `$E82000–$E821FF` | ✅ 16/256色のGRB555と65536色の上下位8bit変換表を実装（65536色は512ドット以下のみ） |
| テキストパレット | `$E82200–$E823FF` | ✅ 16色GRB555を実装。SP/BGと共有 |
| コントラスト | `$E8E001` | ✅ 下位4bitの目標値を即時読出しへ反映し、描画値はフレームごとに45段階で追従。合成後の行へ線形LUTを一度だけ適用 |

SON はスプライトコントローラの `$EB0808` DISP/CPU と論理積です。色コード0ではなく、
GRB555生値が `0x0000` の画素を透過候補とします。

## 既知の制約

- GRB555のIビット、R2のYS/VHTは未対応。
- コントラストの物理カーブは未確定で、線形LUTはXEiJに基づく近似です。
- `$E8E001` の上位4bit読出しとシステムポートの広域ミラーは未検証。
