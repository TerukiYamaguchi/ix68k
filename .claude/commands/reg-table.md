# I/Oポートレジスタ図の表化

技術書 PDF の I/O レジスタ図（OCR で崩れたテキスト）を Markdown テーブルに整形する。

## 1. 高解像度 OCR でページ取得

```bash
swift "<PDF_OCR_SCRIPT>" \
  "<PDF絶対パス>" <ページ番号> 2>&1
```

PDF パス例:
- `local/refs/InsideX68000.pdf`
- `local/refs/Human68k_3.0_Users_Manual.pdf`

## 2. OCR テキストの読み方

レジスタ図は2列レイアウトが1列に線形化される:
- **左列**: bit番号 → 信号名 → (ピン名) の順
- **右列**: 各ビットの説明（**逆順**で出力されることが多い＝bit0の説明が先）

OCR 誤読の典型パターン:
| 誤読 | 正 | 備考 |
|-----|-----|------|
| `SE88001` | `$E88001` | S → $ |
| `bito` / `bit O` | `bit0` | O → 0 |
| `FMIRO` | `FMIRQ` | O → Q |
| `TAO` | `TA0` | O → 0 |

## 3. テーブル形式

### ビット配置図（GPIPレジスタ・割り込みレジスタ等）

```markdown
| bit | 信号名 | 説明 |
|-----|-------|------|
| bit7 | H-SYNC (GPIP7) | CRTCのH-SYNC信号の状態。1=H-SYNC期間、0=非期間 |
| bit6 | ... | ... |
```

### レジスタ一覧（アドレス・略称・ビット配置・名称）

```markdown
| 種別 | アドレス | 略称 | bit7〜bit0 | レジスタ名 |
|------|---------|------|-----------|-----------|
| GPIP制御 | $E88001 | GPIP | GPIP7 GPIP6 ... GPIP0 | 汎用I/Oレジスタ |
| | $E88003 | AER | GPIPと同様 | アクティブエッジレジスタ |
```

## 4. 注意事項

- **ユーザー訂正を優先**: OCR が読めない箇所はユーザーに確認。自分の知識で補完した場合はその旨を伝える。
- **複数ページ**: 図が複数ページにまたがる場合は連続して OCR し、まとめてテーブル化する。
- **未使用ビット**: 「未使用」または「—」と記載。
