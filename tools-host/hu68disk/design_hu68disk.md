# hu68disk 設計

## 1. 目的と構成

`tools-host/hu68disk/` は、Human68k ディスクイメージをホスト側で操作する C99 ツールである。
VFAT の LFN エントリを作らず、Human68k ネイティブの長名と Shift-JIS を扱う。

| モジュール | 責務 |
|---|---|
| `sjis.c` | UTF-8 と Shift-JIS（CP932）の変換 |
| `image.c` | イメージ種別判定、パーティション選択、BPB、範囲検査、読み書き |
| `fat.c` | FAT12/FAT16 のクラスタチェーンとファイルデータ |
| `dir.c` | ディレクトリエントリ、名前、パス、日時 |
| `cmd.c` | ファイル操作、`mkfs`、区画操作 |
| `fsck.c` | 整合性検査と修復 |

## 2. ファイルシステムと名前

- 対象は 2HD フロッピー（FAT12）と XEiJ 互換 SCSI HDD（FAT16 / `.HDS`）。
- Human68k の長名は、ディレクトリエントリの名前部 8 バイトと予約領域 10 バイトを連結して
  格納する。最大は名前 18 バイト、拡張子 3 バイトであり、VFAT の別エントリは生成しない。
- ディスク上の名前は Shift-JIS。ホスト境界で UTF-8 と相互変換し、SJIS の第2バイトを
  拡張子区切りと誤認しない。
- SCSI HDD の FAT16 はビッグエンディアン、ディレクトリエントリはリトルエンディアンである。

## 3. SCSI HDD とパーティション

SCSI HDD は `X68SCSI1` のデバイスパラメータと最大15スロットのパーティションテーブルを持つ。
区画番号は検出順ではなくテーブルの 1--15 番スロット番号である。

- `partitions` は区画を一覧し、`--all` で空きスロットも表示する。
- ファイル操作と `fsck` は `--part N` で区画を選択する。指定なしは最初の利用可能な
  Human68k 区画を選ぶ。
- `copyall` は `--src-part N` と `--dst-part N` を独立して指定できる。
- `mkfs --type scsi --volume MiB[:LABEL]` は1--15個の連続した Human68k 区画を生成する。
  第1区画は boot、第2区画以降は usable とする。
- `--no-partition` は Human68k 区画を確保しない HDS を作り、NetBSD/x68k などの
  自前ファイルシステム用インストール先に用いる。

GB 級 HDS を扱うため、SCSI HDD はイメージ全体ではなく、ヘッダまたは選択区画だけを
メモリへマップする。読み書きは選択区画の範囲内に制限する。

## 4. 作成・ファイル操作

`list`、`copy`、`del`、`extract`、`mkdir`、`rmdir`、`copyall`、`mkfs`（別名 `format`）を提供する。
既存イメージを `mkfs` する場合は確認を要求し、`--force` でのみ無確認上書きを許す。

`mkfs --type scsi` は XEiJ 互換の IPL、デバイスドライバ、パーティション IPL をイメージへ
書き込む。これらは Human68k にドライブとして認識させるため必須である。容量に応じて
クラスタサイズを選び、FAT16 のクラスタ数を上限内へ保つ。

## 5. fsck

`fsck`（別名 `check`）は既定で診断のみを行い、`--fix` 指定時だけ修復する。

- 検査対象は FAT 予約マーカー、VFAT LFN 混入、`.`／`..`、範囲外・循環・クロスリンクした
  クラスタチェーン、ファイルサイズ、lost cluster。
- 第2FAT以降との一致は検査しない。Human68k は第2FATを維持しないため、実イメージでは
  不一致が正常に起こる。
- `--fix` は既定で `<image>.bak` を作成してから修復し、修復後に再検査する。
- 終了コードは 0=正常または全修復、1=問題残存、2=使用法エラー。

## 6. 検証

- `make test`：FAT、名前、ファイル操作、SCSI HDD、複数区画、fsck を自己検証する。
- XEiJ の HDS とメタ領域をバイト比較し、Human68k と `list`／`copy`／`extract` を相互検証する。
- `mkfs` 済み HDS を ix68k で起動し、2GB イメージと 1GiB 境界を越える Read(10) も確認済み。

詳しい CLI と運用例は `tools-host/hu68disk/README.md` を正本とする。
