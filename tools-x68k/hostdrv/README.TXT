			   HOSTDRV.SYS Ver.1.0

			   ホスト共有ドライブ・デバイスドライバ

					    programmed by Mitsuky


  ホスト側の1つのディレクトリを、Human68k のリモートドライブとして使える
ようにするデバイスドライバです。DIR・COPY・CD・プログラムの実行など、通
常のドライブと同じように操作でき、ファイルの作成・変更・削除はホスト側へ
反映されます。


● 動作環境及びインストール

  ix68k 専用です。他のエミュレータや実機に組み込もうとすると「ix68k 以外
では組み込めません」と表示され、ドライブは登録されません（起動は続行しま
す）。

	1. HOSTDRV.SYS を \SYS\HOSTDRV.SYS へコピーします。
	2. CONFIG.SYS に次の行を追加して再起動します。
		DEVICE = \SYS\HOSTDRV.SYS

	3. 共有するホスト側のディレクトリを、ix68k.cfg の hostdrv_dir =
	   <ディレクトリのパス> で指定します。

  hostdrv_dir が空、または存在しないパスのときは「ホストディレクトリが未
設定のため組み込みません」と表示され、ドライブは登録されません（起動は続
行します）。


● 起動方法

  CONFIG.SYS から自動で組み込まれます。起動時に、割り当てられたドライブ
文字が表示されます。

	HOSTDRV Ver.1.0: A: をホスト共有ドライブに割り当てました。

  ドライブ文字はほかのデバイスドライバの登録順で変わります。表示された文
字を使って下さい。


● オプション

  デバイスドライバ自身のオプションはありません。


● 注意

	・CD .. のような相対的な親ディレクトリへの移動は失敗します。CD
	  A:\ のように絶対パスを使って下さい。
	・共有ディレクトリの外側へはアクセスできません。
	・ファイル名はゲスト側が Shift-JIS、ホスト側が UTF-8 として扱わ
	  れます。変換できない文字を含む名前は避けて下さい。
	・CONFIG.SYS の他のドライバでドライブ文字を A:～Z: で明示指定し、
	  ドライブ文字に空きができると、その後に登録するデバイスドライバ
	  で Human68k がアドレスエラーを起こします。明示指定するドライバ
	  には「*:」か「@:」を使って下さい。
	・稼働中のディスクイメージをホスト側から直接書き換えないで下さい。


● 配布規定

  配布＆改造自由のフリーウェアです。ソースの引用＆組み込みも自由です。い
ずれの場合も連絡の必要はありません。

  また、大変申し訳ありませんが、本プログラムは無保証であり本プログラムに
起因するいかなる損失にも免責とさせて頂きます。
