			   FNTADR.X Ver.1.0

			   ANKフォントアドレス報告ツール

					    programmed by Mitsuky


  現在有効な ANK フォントの実アドレスを IOCS _FNTADR で取得し、
「FNTADR=XXXXXXXX;」の形でエミュレータへ報告します。

  HIOCS PLUS などの常駐ドライバが ANK フォントを実行時に差し替えていると、
MCP の read_bitmap_text や run_command は、ROM 固定オフセットの CGROM パ
ターンと照合するため文字を誤認識します。本ツールで報告すると、以後の文字
認識が現在のフォントを基準にします。


● 動作環境及びインストール

  ix68k（X68000エミュレータ）上の Human68k で動作します。FNTADR.X を
PATH の通ったディレクトリへコピーして下さい。報告を受け取るのは ix68k 本
体（_B_PRINT の出力を監視しています）のため、他のエミュレータや実機では
意味がありません。


● 起動方法

	FNTADR

  フォントを切り替えた直後（例: HIOCS C:\SYS\VAX.FON の実行後）に毎回実
行して下さい。画面に「FNTADR=XXXXXXXX;」の行が出ます。

  リセットすると報告は失われ、ROM 固定オフセット参照に戻ります。リセット
のたびにフォントを切り替える場合は、その後でもう一度実行して下さい。


● オプション

  オプション・引数はありません。


● 配布規定

  配布＆改造自由のフリーウェアです。ソースの引用＆組み込みも自由です。い
ずれの場合も連絡の必要はありません。

  また、大変申し訳ありませんが、本プログラムは無保証であり本プログラムに
起因するいかなる損失にも免責とさせて頂きます。
