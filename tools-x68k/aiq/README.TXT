			   AIQ.X Ver.0.9

			   自然言語によるコマンド実行支援ツール

					    programmed by Mitsuky


  日本語の指示文をRS-232C経由でホスト側ブリッジ（aiq-bridge）へ送り、返
ってきたHuman68kのコマンド列を確認したうえで順に実行します。コマンドはホ
スト側では実行されません。AIQ.X が提案を受け取り、ゲスト上で実行します。


● 動作環境及びインストール

  ix68k（X68000エミュレータ）上の Human68k で動作します。AIQ.X を PATH
の通ったディレクトリ（\BIN など）へコピーして下さい。

  ホスト側には aiq-bridge（Python 3 標準ライブラリのみ、tools-host/
aiq-bridge/）と、Claude API・Codex API・LM Studio のいずれかの LLM が必
要です。配布ZIPの aiq-bridge は macOS / Linux 版のみです。

  ix68k は X68K_RS232_PTY=1 を付けて起動し、起動ログに出る RS-232C PTY
slave のパスを、aiq_bridge.py の --tty に渡して下さい。


● 起動方法

	AIQ <指示文>

	例）AIQ ディスクの空き容量を教えて

  AIQ -V でバージョンを表示します。引数なしで起動したときも、バージョン
と使い方を表示します。

  指示文は空白で連結され、全体で255バイトまでです。実行すると次のように
動作します。

	1. 指示文をホストへ送り、「ホストに問い合わせ中...」と表示して応
	   答を待ちます。応答待ちは最大90秒です。[ESC] で中断できます。
	2. ホストの回答と、実行するコマンド列（最大32本）を表示します。
	3. 「実行しますか? [y/N]」と聞くので、y か Y で実行、それ以外は
	   取りやめます。
	4. コマンドは COMMAND.X /C で1本ずつ実行します。1本でも失敗した
	   ら、そこで停止します。

  DEL・DELETE・ERASE・FORMAT・RD・RMDIR・COPY・MOVE は内容を変更・削除す
る可能性があるため、コマンド列の表示で [!] が付きます。y を押す前に必ず
確認して下さい。


● オプション

  オプションはありません。引数はすべて指示文として扱われます。引数なしで
起動すると使い方を表示します。

  終了コードは、正常終了または実行の取りやめが 0、ホストとの通信失敗・指
示文が長すぎる・コマンドの失敗が 1 です。


● 注意

  ホスト側ブリッジの動作確認は LM Studio との組み合わせのみです。Claude
API と Codex API は未確認です。LLM が提案するコマンドは正しいとは限りま
せん。内容を確認してから実行して下さい。


● 配布規定

  配布＆改造自由のフリーウェアです。ソースの引用＆組み込みも自由です。い
ずれの場合も連絡の必要はありません。

  また、大変申し訳ありませんが、本プログラムは無保証であり本プログラムに
起因するいかなる損失にも免責とさせて頂きます。
