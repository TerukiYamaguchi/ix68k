			   HOSTFILE.X Ver.1.0

			   ホスト・ゲスト間ファイル転送ツール

					    programmed by Mitsuky


  稼働中の ix68k とホストの間で、ファイルを1本ずつやり取りするコマンドで
す。HOSTDRV と違い、通常の DOS コールで実際のドライブに読み書きするため、
Human68k のキャッシュと矛盾しません。


● 動作環境及びインストール

  ix68k（X68000エミュレータ）上の Human68k で動作します。HOSTFILE.X を
HOSTDRV のドライブなどからゲストへ渡し、PATH の通ったディレクトリへコピ
ーして下さい。

  ホスト側の相手は、tools-host/ix68k-hostfile/ix68k-hostfile、または MCP
の hostfile ツールです。


● 起動方法

	HOSTFILE GET <出力ファイル名>
	HOSTFILE PUT <入力ファイル名>
	HOSTFILE -V

  HOSTFILE -V でバージョンを表示します。

	・GET: ホスト側が put したファイルを受け取り、<出力ファイル名>
	  で保存します。
	・PUT: <入力ファイル名> のファイルをホストへ送ります。ホスト側は
	  get で回収します。

  GET / PUT は Human68k から見た動作です。ホスト側の ix68k-hostfile の
put / get とは語が逆になります。ホストが put したものをゲストが GET し、
ゲストが PUT したものをホストが get します。GET / PUT は小文字でも構いま
せん。


● オプション

  オプションはありません。引数は「GET か PUT」と「ファイル名」の2つちょ
うどです。それ以外では使い方を表示します。


● 配布規定

  配布＆改造自由のフリーウェアです。ソースの引用＆組み込みも自由です。い
ずれの場合も連絡の必要はありません。

  また、大変申し訳ありませんが、本プログラムは無保証であり本プログラムに
起因するいかなる損失にも免責とさせて頂きます。
