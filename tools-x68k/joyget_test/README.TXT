			   JOYGET_TEST.X Ver.1.0

			   ジョイスティック割り当て確認ツール

					    programmed by Mitsuky


  IOCS _JOYGET の値を画面に表示するツールです。ゲームが読む値と同じもの
を確認できます。パッドがジョイスティック#1・#2のどちらに割り当たったかを
調べ、ix68k.cfg の joy1 / joy2 を決めるのに使います。


● 動作環境及びインストール

  ix68k（X68000エミュレータ）上の Human68k で動作します。JOYGET_TEST.X
をゲストへ渡して下さい（HOSTDRV のドライブ経由など）。インストールは不要
で、そのまま実行できます。


● 起動方法

	JOYGET_TEST

  画面上部にバージョンが表示されます。画面に「JOY#1:」「JOY#2:」の2行が出ます。パッドのボタンを1つずつ押し、
どちらの行にボタン名が出るかを見て下さい。[ESC] で終了します。

  X68000 のジョイスティックポートは、4方向と2ボタンしかありません。
SELECT は上下の同時押し、START は左右の同時押しとして表示されます（この
間は上下・左右も押された扱いで表示されます）。


● オプション

  オプション・引数はありません。


● 設定の変え方

  使いたいパッドが「JOY#2:」に出る場合は、ix68k.cfg の joy1 / joy2 に、
起動ログの「Gamepad#N」の番号 N（1～8）を指定して ix68k を再起動して下さ
い。

	joy1 = 2
	joy2 = 1

  この例は、Gamepad#2 を#1に、Gamepad#1 を#2にします。


● 配布規定

  配布＆改造自由のフリーウェアです。ソースの引用＆組み込みも自由です。い
ずれの場合も連絡の必要はありません。

  また、大変申し訳ありませんが、本プログラムは無保証であり本プログラムに
起因するいかなる損失にも免責とさせて頂きます。
